When an activity is completed and submitted, it becomes a report that you can view and analyze. Open reports from the Overview Dashboard or the Kanban Board.

From the Overview Dashboard

1. Go to the Overview Dashboard from the home page.

2. Choose the activity group (for example My Activities, or Facility Activities if you have permission) and the type of activity.

3. In the Status Window, click Submitted.

4. In the far right column, click View Report.

A window opens showing the responses submitted in the activity. Use the navigation pane on the right to move between the pages of the report.

The report has an overview section and collapsible pages.

From the Kanban Board

  1. In the Daily Standard Work menu, click Kanban Board.

  2. Find the activity in the Submitted column.

  3. Open the report from the activity's card.

Good to know

  • Click a photo in the report to open it full size.

  • Click Download report to download it. Photos are not included in the download yet.

  • Filter submitted activities by date, label and template type. The Submitted view also shows each activity's start and end time.

  • The DSW Reports page (left navigation) shows completed vs pending activities, flagged items over time, submissions by user and a list of flagged questions.

  • Template owners can also see submissions in Lean Creator: open the template and use the Submissions and Reporting tabs. Flagged and critical responses appear there.

Note: There is no monthly roll-up report. To build one, use a Lean Studio dashboard.
