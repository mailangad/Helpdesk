NEW FEATURES

Suggestion Module

  • Saved Views & Group By on Dashboard: You can now save your custom views and use the "Group By" feature on the Suggestion dashboard (This allows for deeper data analysis and quick access to your most important datasets).

  • RICE Matrix & Prioritization Score: Implemented the RICE (Reach, Impact, Confidence, Ease) framework to calculate a prioritization score for suggestions (This provides a standardized, data-driven method for evaluating and ranking ideas).

Daily Standard Work (DSW)

  • Role & Asset-Based Scheduling: The system now supports scheduling DSW activities at the Role level and directly to an Asset level (This allows for greater flexibility and is ideal for assigning CILR - Clean, Inspect, Lubricate, Retighten - activities to specific equipment or teams). See How to assign a template.

LMS & Reporting

  • New Quiz Performance Report: A new report is available on the LMS dashboard that provides visibility into individual quiz percentages (This helps you quickly assess trainee comprehension and identify knowledge gaps).

  • Facility Filter on Course Analytics: A new "Facility" filter has been added to the Course Analytics report (This allows for more granular, location-based analysis of your training data).

  • Trainee Performance Card UX: The Trainee Performance card in Course Analytics has been updated with a new design (This provides a more intuitive and user-friendly visual experience).

User Profile

  • Reorganized User Profile UI: The User Profile page has been updated with a more organized and intuitive layout (This makes it easier to find and manage user information, skills, and permissions).

Platform & User Management

  • Fiscal Year Support: Added the ability to configure and manage data based on your company's fiscal year (This ensures all financial reporting aligns with your internal accounting periods).

  • New User Signup: A new signup feature has been implemented (This provides a streamlined and secure process for new users to register and join the platform).

BUG FIXES & IMPROVEMENTS

Key Performance Indicators (KPI)

  • Resolved several issues related to KPI tracking and reporting (This ensures greater accuracy and reliability of your performance metrics).

Tag Management

  • Real-time Field Configuration Sync: Settings for Tag fields are now synchronized in real-time for all users within a facility (This ensures all users are working with the most up-to-date configurations).

  • The search text filter now works correctly when the "Group By" feature is active on the Tag and Suggestion dashboards (This allows you to reliably search within your grouped data).
