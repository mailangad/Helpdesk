Tag Settings contains the configuration options that control how F-Tags are handled in your workspace.

Who can do this: administrators set up the workflow for the Tags module in the Workflow builder.

To open it, select Tag Settings, the last option in the F-Tag parent menu.

Main sections

The settings are grouped into three tabs:

General Configuration

Set User Re-Assignments, the limit on how many times a tag can be reassigned. Turn on Track User Re-Assignments, set the Counts with the − and + buttons (a minimum of 3 is recommended) and click Save.

Default Assignee

Add and edit Default Assignees: the rules that assign new tags automatically, for example by department or type.

Settings

Edit default due dates, issues and sub-issues, priorities, trade types and Tag Labels.

Together, these settings configure the F-Tag system in your workspace. Most of them appear as fields when you create a new F-Tag. See Create an F-Tag.

Other configuration options

  • Tag Types: create, edit and delete Tag Types, each with its own colour. Users choose a Tag Type when they create a tag, and it appears as a column on the dashboard.

  • One form for all Tag Types: you can't set different fields for each type, but you can use different workflows or tiers.

  • Rename and hide fields: rename fields to match your terms (for example, Trade Type to "Issue category") and hide the ones you don't use. See Add and edit fields when creating an F-Tag.

  • Priorities: define priorities that match your response times, for example "<24h" or "<48h".

  • Reassignment limit: when a tag reaches the reassignment limit set in General Configuration, reassignment is locked and the manager is notified.

  • Floor Plan: set up the floor plans of your facility. Tags are shown on the plan by location, you can drag and drop pins to reposition them, and you can configure the size of the dots that represent tags.

  • Kanban Board: the Kanban board shows tags as cards in status columns. The statuses and the transitions between them come from the workflow for the Tags module, which administrators set up in the Workflow builder.

  • Tier escalation: configure escalation tiers (Tier 1, Tier 2 and Tier 3). A tag can be escalated between tiers with a comment, and the members of the tier receive an email.
