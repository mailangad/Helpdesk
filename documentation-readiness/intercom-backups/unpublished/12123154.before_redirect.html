Turn an approved suggestion into a Kaizen when implementing it is a larger job that needs time and resources.

Watch a video walkthrough (1:53)

Before you begin

Important: You can only turn a suggestion into a Kaizen after it has been approved. The suggestion's status must be Pending Implementation.

Steps

1. Open the approved suggestion you want to turn into a Kaizen. You can use the side window or the detail view. These steps use the detail view.

Need help? See Open a suggestion after creation.

2. Open the Mark as Complete drop-down menu and select Initiate Kaizen.

3. Complete the remaining fields in the Create Kaizen window. Some fields are already filled in with information from the suggestion.

4. Click Create in the top right corner.

Note: The Create Kaizen window is the same window used to create a new Kaizen in the Kaizen module. See Create a Kaizen.

Result

The suggestion's status changes to Implemented Kaizen, and the Kaizen module handles the next stages.

Good to know

  • The new Kaizen appears on the Kaizen dashboard. See About the Kaizen Dashboard.

  • The suggestion and the Kaizen are linked both ways, so you can move between them.

  • The converted suggestion keeps its own number, and the Kaizen gets its own ID from the Kaizen sequence.

  • Depending on your point rules, converting a suggestion to a project can earn points. See Set suggestion points in Suggestion Settings.
