The Create KPI window walks you through five sections when you create a KPI. Here is what each section and field does.

To open the window, click Create New on the home page and choose KPI. The five sections are:

  1. KPI Basics

  2. Advanced Details

  3. Frequency

  4. Access & Visibility

  5. Source

Click Save & Next to move from one section to the next. When you have completed all five sections, click Publish.

Section 1: KPI Basics

Field

Description

KPI Name

The name of the KPI, as it appears on the KPI dashboard and in charts.

Pillar

The pillar the KPI belongs to. Pillars are set up for your workspace by LeanSuite.

KPI Description

A short explanation of what the KPI measures and how it is calculated.

KPI Format

The unit or format of the values you record for this KPI.

Target Value

The global target for the KPI. When you enter a value, you can optionally override the target for that day; leave it blank to use the global target.

Section 2: Advanced Details

The rest of the Advanced Details section:

Field

Description

Which direction is suitable for this KPI?

Whether a higher or a lower value is better. For example, choose "lower is better" for scrap or downtime.

How is this KPI aggregated

How values are combined over a period: sum or average.

Is this a calculated KPI

Turn this on to build the KPI from a formula that uses other KPIs, for example A ÷ B.

Calculated by

The KPIs and operation used in the formula of a calculated KPI.

What are your RAG thresholds?

Optional red/amber/green ranges. Each result is colored according to the range it falls in.

Pareto Settings

Turn on Pareto for this KPI and add categories, such as downtime reasons or shifts. You then choose a category when you enter a value, and can view the KPI as a Pareto chart.

Important: Changing the "total" dropdown also turns the KPI into a calculated KPI.

Section 3: Frequency

Field

Description

Start Date

The date the KPI starts being tracked.

End Date

The last date the KPI is tracked, or Never. This is the KPI's lifetime.

Time zone

The time zone used for the schedule and reminders.

Repeat Every

How often a value is due: every N days or weeks, on the weekdays you choose.

Note: The start and end time set the daily window for entering the value. They drive the calendar entry and the reminder email.

Assignee

Visibility (Facility)

Facility

The facility the KPI is shared with.

Assignee

The person responsible for entering values. Assignees receive reminders.

Roles

Section 5: Source

The source decides where the KPI's values come from.

Field

Description

Manual

Users enter values by hand (single entry or bulk) or upload an Excel or CSV file.

Google Sheets

LeanSuite reads values from a connected Google Sheet on a schedule.

Setup/Sign In

Sign in to your Google account and select the sheet to connect.

LeanSuite

Values are calculated from data in other LeanSuite modules.

Module

The LeanSuite module the data comes from.

Facility

The facility whose data is used.

Time Range

The period of data to include.

Date

The date of each value.

Actual

The actual value recorded for that date.

Target

The target value to compare against (optional).

Microsoft Excel

LeanSuite reads values from an Excel file on OneDrive or SharePoint on a schedule.

Setup/Sign In

Sign in with Microsoft, search for the file by name, select the sheet or table, then map Date and Actuals.

Good to know when connecting Excel

  • Allow pop-ups for theleansuite.app. A pop-up blocker stops the Microsoft sign-in window.

  • Your Microsoft 365 admin must approve the Lean connector consent request.

  • Only the OneDrive root folder is searched. Shared drives are not supported yet.

  • The file must keep exactly the same name. LeanSuite reads that file and adds only new dates.

  • One file can feed several KPIs.

For the full steps, see Connect a KPI to Excel or Google Sheets.
