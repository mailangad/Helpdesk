You can choose which fields appear on the Create Kaizen window, and which of them are required.

Who can do this: admins.

Watch a video walkthrough (2:05)

Before you begin

Open the Create Kaizen window as described in Create a Kaizen.

Steps

1. Click Show Fields at the top right of the Create Kaizen window.

The Kaizen Fields Management window opens. It has three columns:

  • Show/Hide: choose which fields are shown or hidden on the create form.

  • Fields: lists all the fields available when creating a Kaizen.

  • Required?: choose which fields are mandatory. Depending on the type or purpose of the Kaizen, some information may be essential for good data collection.

2. Choose which fields to show and which are required.

3. Click Apply at the bottom right to apply your choices to the Create Kaizen window.

A green message confirms that the fields were updated.

4. Fill in the newly visible fields and submit your Kaizen.

Good to know

  • Title, Project Lead, Project Type and Methodology are always required.

  • Admins can use Show Fields to simplify the form, for example by hiding fields your team doesn't use. For an EWO, you can show Breakdown start/end (which calculates downtime automatically) and hide Saving status.

  • The options in fields such as Project Type, Methodology and Loss Type are set up in Kaizen Settings. See About Kaizen Settings.

  • After the Kaizen is created, use More to add sections such as Result/Benefit, Team, Targets, KPIs, Tools/Skills, 5 Whys, 5W1H, 4M and Action Plan. The Target section can track several KPIs.
