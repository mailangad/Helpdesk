The KPI dashboard is the central place where all your KPIs are listed. From the dashboard you can:

  1. View KPIs and their data

  2. Edit existing KPIs

  3. Enter data and values into KPIs

This is what a typical KPI dashboard looks like:

KPI Dashboard

Tabs, filters and search

At the top of the dashboard, three tabs let you switch between All KPIs, Tree KPIs and Indicators.

Use Filters (the number shows how many are applied) and Search KPIs to narrow the list, and click KPI Builder to create a KPI.

The All KPIs tab groups KPIs into Indicator KPIs and Tree KPIs, each with a View All link.

Indicator and Tree KPIs

  • Each Indicator KPI card shows the latest value, the change versus the prior period and a small trend line.

  • Each Tree KPI row shows the number of children, its Status (for example Publish), a Health Score and a KPI Tree link.

  • At the bottom, How to Build KPI Trees summarizes the steps: Open KPI Builder, Create or Build, and View Roll-ups.

Open a KPI

Click any KPI to open its details. From there you can:

  • click Input Value to enter data

  • click the pencil icon to edit it (see Edit a KPI)

  • click Recent Trends to view its history and charts
