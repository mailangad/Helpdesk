Phases and sections are linked. Sections are added to phases, phases belong to a methodology, and the methodology is attached to a Kaizen. Together they create a structured, step-by-step improvement process.

Watch a video walkthrough (1:12)

Phases

When you create a Kaizen, one of the fields you fill in is Methodology. To learn more, see Create a Kaizen.

A Kaizen methodology is the method the Kaizen follows. It has phases, which you can think of as the steps the Kaizen moves through (for example Plan, Do, Check, Act, or Define, Measure, Analyze, Improve, Control).

Admins can create a new methodology and add the phases they need. See Add a Kaizen methodology.

When a methodology is attached to a Kaizen during creation, its phases are attached to the Kaizen automatically. You see these phases when you open the Kaizen. See About the Kaizen side window.

Sections

Below the phases of a Kaizen you can see sections. Some sections are attached to specific phases.

Sections are the tools, methods and process types you add to a phase to help that phase progress.

Some sections are ready to add to a phase, and you can also create new sections as needed.

Note: sections contain further options, such as appointing a team, adding tools and allocating hours, depending on the methodology or section chosen. See Kaizen phase sections.

Good to know

  • In Kaizen Settings, an admin adds a template to each phase of a methodology and chooses which sections open automatically in that phase.

  • Days can be set in total or by phase, and due dates are then set automatically.

  • Custom sections can be built in Lean Creator with Template Type = Kaizen. They then appear in Kaizen Settings and under the More sections of a Kaizen.
