Start and submit an activity assigned to you in Daily Standard Work (DSW), from the Overview dashboard or the Kanban Board.

Open Daily Standard Work

From the home page, open Daily Standard Work.

You can start an activity assigned to you in two ways:

  • From the Overview Dashboard (steps below)

  • From the Kanban Board (see "Start from the Kanban Board" below)

Find the activity on the Overview Dashboard

1. In the top menu bar, click My Activities.

2. In the options directly below the main bar, choose In Progress, Upcoming or Overdue.

Start the activity

3. In the Action column, click Start for the activity you want to begin. The template (built in Lean Creator) opens.

Complete and submit

4. Answer the questions and attach photos where required.

5. Click Submit in the bottom right corner of the last page.

The submitted activity then appears in the Submitted column, where you can view it as a report.

Start from the Kanban Board

  1. In the DSW menu, click Kanban Board.

  2. Find the activity in the Overdue, In Progress or Upcoming column.

  3. Start the activity from its card, then complete and submit it as described above.

Good to know

  • You can also open assigned activities from your Dashboard or Calendar, in the web app or the mobile app.

  • If you spot an issue while completing a template, you can create an F-Tag, Kaizen or Suggestion directly from the Submit Template page.

  • If a view doesn't display correctly, refresh the page.
