Every module in LeanSuite has its own dashboard and parent menu. The parent menu holds the main options of the module, and each option opens in the dashboard area.

To open the Kaizen parent menu, select Kaizen on your account home page. The Kaizen parent menu (dark blue background) has two states.

State 1

State 1 is shown as soon as you open the Kaizen module from your account home page.

This is the current Kaizen menu:

The Kaizen parent menu options are:

  • Kaizen Dashboard

  • Kaizen Settings

  • Kaizen Reports

  • Approval Dashboard

State 2

State 2 becomes active when you select Kaizen Settings in State 1. The State 1 options are hidden and new options are shown.

The Kaizen settings and features panel has:

  • Savings Distribution

  • Kaizen Settings

  • Loss Management

  • Tool Management

  • Revised Due Date Reasons

Tool Management extends Loss Management. You use it to create tools that can be connected to a loss type, and it keeps a dashboard-style record of all tools created.

Revised Due Date Reasons lets you define the reasons for a delay in implementing a Kaizen.

Each Kaizen has a start date and a due date. The due date can change for technical, labor, mechanical, logistical or other reasons, depending on your company and industry.

Every time a Kaizen's due date changes, LeanSuite requires a reason for proper documentation and transparency. This option is where you create the reasons that can be selected.

Right-side panel

When you select an option in either state of the left menu, it opens in the right-side panel (white background). The selected option is highlighted in the menu to show that it is active.

Think of the left menu as the controls and the right-side panel as the display. All the details of a Kaizen, from its information to its editing options, are shown in the right-side panel.

The two panels work together to help you add, edit, navigate and progress Kaizens.

Good to know

  • The waffle icon next to the logo lets you jump between modules, including Workflow, where admins build the workflow for each Kaizen project type.

  • Use the facility switcher at the top left to change facility. The Kaizen Dashboard list follows the facility you select.

  • The Kaizen Dashboard now includes a Gantt view and saved views.

  • The home page icons were refreshed in March 2026, so they may look different from the screenshots in this article.

Who can do this: the gear menu is visible to admins only. If Kaizen Settings is missing after you were given permission, log out and log back in.
