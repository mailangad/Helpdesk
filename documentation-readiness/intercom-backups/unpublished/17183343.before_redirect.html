If a KPI's source is set to manual, you enter its values yourself. You can enter one value at a time, fill in several dates at once, or add values straight from a Lean Studio board.

Enter one value

  1. Open the KPI and click Input value.

  2. Choose the date and enter the value.

  3. If the KPI uses categories, choose one, for example the reason for downtime.

  4. Leave target blank to use the KPI's standard target. Only fill it in to override the target for that date.

  5. Add a comment if needed.

  6. Save.

Enter several dates at once

  1. In Input value, set a date range with the two date pickers in the top right.

  2. Fill in the grid for each date.

  3. Save.

Tip: Entering several dates at once is useful for catching up on missed days or entering past data.

Enter from a Lean Studio board

  1. On a Lean Studio dashboard, click a date on a KPI widget.

  2. Click Add KPI.

  3. Enter the value without leaving the board.

View your data

Click View KPI to see history by week or month.

Switch the chart from Bar to Pareto + Trend or pie to see values broken down by category. You can also export to Excel and see linked Kaizens.
