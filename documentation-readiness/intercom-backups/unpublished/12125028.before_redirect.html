Issues and sub-issues pinpoint the area and the problem an F-Tag needs to resolve.

The F-Tag module is also called the Issue Tracker because it tracks the issues in your facility. For an overview, see About the F-Tag module.

You can pre-configure issues and sub-issues for each pillar in your facility. You create them when you configure the module, and you can make them active or inactive at any time.

When someone creates a new F-Tag, the active issues and sub-issues are available to select. See Create an F-Tag.

Examples

Example: the painting department may need its workspace cleaned regularly, and after spills or leaks. You can create a main issue for Cleaning, with sub-issues for the cause, such as a spill, a leak or another accident.

Example: you can also use issues to inspect machines and equipment. When a machine needs frequent maintenance, create an issue with sub-issues for the parts that need checking. Users can then select this issue whenever the equipment has a problem or is not working properly.

Why issues help

With a priority and a pillar attached to the issue, the default assigned team can pick it up quickly and resolve it. This prevents loss of time, cost and labour, and reduces the risk of injury from faulty equipment.

Issues add detail to each F-Tag and save time by routing the task to the right assignees.
