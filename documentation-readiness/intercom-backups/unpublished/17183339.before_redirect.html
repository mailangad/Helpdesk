Instead of typing KPI values in by hand, have LeanSuite read them automatically from an Excel file on OneDrive or SharePoint, or from a Google Sheet.

Before you begin

  • Allow pop-ups for LeanSuite in your browser. The Microsoft or Google sign-in opens in a pop-up.

  • For Microsoft: your company's Microsoft 365 admin may need to approve the LeanSuite connector the first time. If you see an approval request, send it to your IT team.

Connect the file

  1. Open the KPI, go to the Source step, and choose Excel (Microsoft) or Google Sheet.

  2. Sign in and search for your file by name.

  3. Select the sheet or table.

  4. Map the columns: the date column and the actual value column. You can also map target and category if your file has them.

  5. Set how often LeanSuite reads the file: time of day, time zone, repeat, and end date.

  6. Save.

Rules for the file

Important: Keep the same file name. LeanSuite reads the same file every time and adds any new dates. If your system exports a new file each day with a different name, for example with the date in it, save or rename it to the same fixed name, replacing the old one.

  • OneDrive: search looks in your OneDrive root folder. Keep the file there. Shared drives aren't supported yet.

  • One file can feed several KPIs. Map a different column for each.

Uploading a file instead

You can also upload a file whenever you need to:

  1. Open the KPI and click Upload file.

  2. Choose the Excel or CSV file.

  3. Map the date, actual, and optional target and category columns.

  4. Upload.

Important: Remove empty rows and unused columns first, because they can make the upload fail.

Machine or system data

If your machines or MES can export a daily file to SharePoint, connect that file as above. For direct system connections, contact your LeanSuite representative.
