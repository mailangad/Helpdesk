On the Kaizen Dashboard, you can search for a Kaizen by its name or ID, or narrow the list with filters. You can also save the filters you use most as a view.

Watch a video walkthrough (1:39)

To learn how to reach the dashboard, see About the Kaizen Dashboard.

Search by name or ID

Enter the name or ID of the Kaizen in the search box at the top left.

Note: the search box only searches the ID and title (name) of a Kaizen. To search by any other information, use the filters described below.

Search using filters

Filters are criteria the dashboard uses to show only the matching Kaizens.

  1. Select one of the filters next to the search bar.

  2. Choose an option from the drop-down menu.

The filter turns blue and shows your choice, to indicate that it is active. The matching results are shown below.

Filter tips

There are many filters available, based on the information inside a Kaizen, including a Year filter.

  • Click More to see all the available filters.

  • Click Clear All at the far right to clear all filter criteria.

  • To remove a single active filter, click the x icon next to its drop-down button. This clears the filter and also removes it from the visible list.

  • To bring back a filter you removed with the x icon, click More.

Save and pin a view

If you often use the same filters, save them as a view so you don't have to apply them again each time.

  1. Apply the filters you want.

  2. Click Save view.

  3. To open the dashboard with this view by default, pin it.

You can save several views, but only one can be pinned per dashboard.

Note: there is a known issue where the pinned view may not persist after a page refresh or when you switch modules.

Good to know

  • Use the column picker, to the left of the refresh icon, to rearrange or hide columns.

  • The dashboard list follows the facility selected in the facility switcher.
