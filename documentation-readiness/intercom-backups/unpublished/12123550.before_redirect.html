The parent menu of the Kaizen module has two states. Each option opens in the right-side panel.

Watch a video walkthrough (1:28)

To learn how to reach the parent menu, see About navigation in the Kaizen module.

State 1 options

  • Kaizen Dashboard: lists all the Kaizens created in your facility, with table, list and Gantt views, filters and saved views.

  • Kaizen Settings: does two things at once. It opens the Add New window in the right-side panel, and it activates State 2 of the parent menu.

  • Approval Dashboard: lists all the Kaizens waiting for approval of a due date change.

  • Reports: a statistics dashboard for the Kaizen module.

State 2 options

State 2 is the features menu of the Kaizen module. The feature options appear above and below the Kaizen Settings option in the parent menu.

  • Savings Distribution: tracks and allocates the savings of a Kaizen as required.

  • Kaizen Settings: does two things at once, as described under State 1.

  • Loss Management: creates and manages the loss types connected to a Kaizen. See Add a loss type in Kaizen.

  • Tool Management: creates tools to connect with a loss type.

  • Revised Due Date Reasons: defines the reasons that can be given for a delay in implementing a Kaizen. See Add a revised due date reason.
