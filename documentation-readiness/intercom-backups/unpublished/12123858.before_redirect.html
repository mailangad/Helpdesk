Create a Kaizen straight from a loss in a Loss Tree so your team can fix the cause of the loss.

Steps

1. Log in to your LeanSuite account with your credentials.

2. Open the Loss Tree you want to create a Kaizen for. Need help? See Open an existing Loss Tree.

3. Go to Section 2 (Loss results) in the Detail View. Need help? See About the Loss Tree detail view.

4. Find the loss type you want to create a Kaizen for.

5. At the right end of that loss, click Create Kaizen. The Create Kaizen window opens.

6. Enter the required information. Need help creating a Kaizen? See Create a Kaizen.

7. Click Create.

Note: When you create a Kaizen from a loss in a Loss Tree, information related to the loss, such as department, asset and line, is filled in automatically.

Good to know about the Create Kaizen window

  • The required fields are Title, Project Lead, Project Type and Methodology.

  • Admins can use Show fields to hide fields or make them required, so the form you see may differ.

  • After creating the Kaizen, you can add labels and record hard and soft savings in the Result/Benefit section.

  • Due-date changes are tracked on the Kaizen dashboard in the Revised Due Date column.
