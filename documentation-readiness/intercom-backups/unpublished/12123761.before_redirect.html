The Action Plan section lets you add action items to a Kaizen.

It works like a to-do list for the Kaizen. You add an action item, the responsible team member carries out the task, and then marks it as closed.

You use the Action Plan section in three stages: adding an action, performing it, and communicating the result.

Stage 1: Add an action

  1. Add the Action Plan section to the required phase. You can also add it from More on the Kaizen. See Add or remove sections from Kaizen phases.

  2. In the section, click Manage actions → Add new.

  3. Enter a Title and a Description.

  4. Choose the Action Type (for example, corrective or preventive).

  5. Add the assignee: search for and select the person responsible.

  6. Set the date (deadline) for the action in the calendar.

  7. Add the action, as shown in the video walkthrough.

  8. Refresh the page to see it in the list, because the list doesn't refresh automatically.

Stage 2: Perform the action

The assignee carries out the action on site, or as described in the action item.

Stage 3: Communicate the result

When the action is complete, click Mark As Close on the action item.

Related features

  • RCA Agent: after you run RCA Agent → Run RCA Analysis from the Kaizen project toolbar, you can push the suggested actions to the Action Plan.

  • Gantt view: the Kaizen dashboard has a Gantt (timeline) view that shows project schedules, with delay tracking (days delayed) and Revised Due Date. See About the Kaizen Dashboard.
