Clone an existing team to create a similar team quickly. The new team starts with the information from the source team.

Watch a video walkthrough (1:25)

Steps

1. Log in to your LeanSuite account with your credentials.

2. Open the Team Dashboard by clicking the Skill Matrix icon on the home page.

3. Click the team you want to clone. The Team Detail window opens.

4. Click the Clone icon next to the team name. The Create Team window opens, with the fields already filled in from the source team.

5. Change the fields as needed.

6. Follow the same steps as when you create a new team, then click Save. For help, see Create a new team.
