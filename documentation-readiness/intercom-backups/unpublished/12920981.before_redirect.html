The Schedule Dashboard is where you assign activities and see the activities that have already been assigned.

It is the fifth option in the Daily Standard Work (DSW) menu, after Overview, Schedule Calendar, Kanban Board and My Templates.

What the dashboard shows

The dashboard is the central list of all assigned activities. From it you can search, filter, edit, delete and export assigned activities.

The toolbar at the top has Search by Template, Filters, a column settings button and refresh on the left. On the right are Export, Calendar View and Assign.

The list shows these columns:

  • Assignees

  • Title

  • Template Name

  • Event Start Date & Time

  • Event End Date & Time

  • Action

Who you can assign to

Click Assign to create a schedule. You can assign a template to:

  • Users: each selected user must complete it.

  • A role: the item is marked complete for everyone in the role once one member completes it.

  • An asset (Department → Line → Workstation → Asset): the history is kept on the asset. This is ideal for CILR (Clean, Inspect, Lubricate, Retighten) and machine checks.

Tip: You can also schedule a template straight from Lean Creator, using ⋮ → Assign on a published template.
