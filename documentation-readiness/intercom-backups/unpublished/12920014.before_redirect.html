The KPI module lets you define, track and review the key performance indicators that matter to your facility.

You set a target for each KPI, record values on a schedule (manually or from a connected source), and see at a glance whether performance is on track.

What you can do with the KPI module

  • Build KPIs with a guided wizard: basics, advanced details, frequency, access and visibility, and source.

  • Record values daily, weekly or monthly, and receive reminders when a value is due.

  • Compare actual values against targets using red/amber/green (RAG) ranges.

  • Break results down by category with Pareto charts.

  • Roll KPIs up across departments, plants and the whole workspace with KPI trees.

  • Display KPIs on live Lean Studio boards for daily huddles.

Indicators vs KPIs

  • An indicator is the lowest level of measurement, for example the output of a single workstation.

  • A KPI is a roll-up of indicators, for example the output of a whole line or plant.

  • You define KPIs under KPI → Indicators.

When you open Kpi from the home page, the KPI Dashboard shows the All KPIs, Tree KPIs and Indicators tabs, and a KPI Builder button for creating KPIs.

Targets

  • The global target is set on the KPI itself. You can use one global target, or month-by-month targets.

  • When you enter a value, you can optionally override the target for that day. Leave the target blank to use the global target. Target overrides can be locked to certain users.

  • The direction setting tells LeanSuite whether higher or lower is better (for example, "lower is better" for scrap).

RAG ranges

Optional RAG thresholds color each result red, amber or green, so you can spot off-target results immediately on the KPI dashboard and on Lean Studio boards.

Pareto categories

Turn on Pareto for this KPI and add categories, such as downtime reasons or shifts. When you enter a value, you choose its category.

You can then view the KPI as a Pareto chart to see which categories contribute most. Uncategorized values appear separately.

Data sources

Each KPI gets its values from one source:

  • Manual: users enter values one at a time or in bulk, or upload an Excel or CSV file.

  • LeanSuite: values are calculated from data in other LeanSuite modules.

  • Microsoft Excel (OneDrive/SharePoint): LeanSuite reads a connected workbook on a schedule.

  • Google Sheets: LeanSuite reads a connected Google Sheet on a schedule.

KPI trees

KPI trees roll KPIs up from department to plant to workspace.

  • A tree averages its children, so calculate ratios such as OEE at the lowest (leaf) level.

  • Visualize leaf KPIs on charts, not tree KPIs.

  • For cross-plant roll-ups, plants share their KPIs with a "global" facility, which builds the parent KPI. Plants don't see each other's KPIs.

Showing KPIs in Lean Studio

Add KPI widgets to a Lean Studio dashboard to display KPIs live in huddles, including heatmap charts.

You can also enter a KPI value straight from a board: click a date, then click Add KPI.

Tip: If you track several related measures, create separate KPIs and combine them on one Lean Studio chart.
