Edit a Skill Matrix team to update its details, required tools or members.

Who can do this: The creator of a team can see the Edit Team button.

Steps

1. Log in to your LeanSuite account with your credentials.

2. Open the Team Dashboard by clicking the Skill Matrix icon on the home page.

3. Click the team you want to edit. The Team Detail window opens.

4. In the right corner, under the Select Date box, click Edit Team. The Edit Team window opens.

5. Update the fields you need to change.

6. Follow the same steps as when you create a new team. For help, see Create a new team.

Tip: To create a similar team without changing the original, clone it instead. See Clone a team.
