Questions are the building blocks of a template. You add them to pages, or to sections inside a page.

Each question, shown as a question card, has three main parts:

  1. Question field

  2. Response (answer) field

  3. Response properties

Step 1: Enter the question

  1. Open the Lean Creator Window by creating a new template or opening an existing one.

  2. In the question card, type the question in the Question field. This is a text field for the question, instruction or prompt. In the example below, the question text is "Sample Question 1".

Step 2: Choose the response type

  1. Click the Response drop-down and choose how the question should be answered.

When you choose a response type, the response options below the question field update to match it. There are three main response options:

Option

What it does

Required

Makes the question mandatory. The report cannot be submitted until a required question is answered.

Response Properties

Settings for the selected response type. For example, for a multiple-choice question this is where you set the choices.

Add Rule

Available for some response types only. Adds an action that is triggered when a certain response is recorded.

The Add Rule option is available for some response types only.

The response types are:

Response type

What the person answering enters

Assignment

A drag-and-drop box for attaching a file.

Date & Time

The person picks a date and time.

Drag & Drop

A drag-and-drop box for adding files.

Multiple Choice Response

The person chooses from a list of options that you set in the response properties.

Numbers Field

A number. You can set a minimum, maximum and default value.

Text Field

A free-text answer.

Signature

The person signs to acknowledge the step.

Slider

A slider or percentage value, with steps.

Visual Instruction

An image with instructions. Save the image to a file first, because pasting an image does not work.

True or False

A true or false answer.

Checkbox

The person ticks one or more boxes.

Rating

A star rating.

User, Pillar, Department, Line, Workstation, Asset, Process and Shift

Drop-down lists filled from the lists set up for your facility.

You do not need to add name or date questions. The person submitting and the date are captured automatically.

Step 3: Set the response properties

  1. Switch on Required if the question must be answered.

  2. Set the properties for the response type, for example the choices for a multiple-choice question, or the minimum, maximum and default for a number.

  3. Optionally, select Mark this response as flagged/critical or Enable scoring.

Step 4: Add a rule (optional)

Click Add Rule to set a condition (for example "is False" or "> 22.3") and the action that follows. Actions include:

  • Ask a follow-up question

  • Require evidence (a photo and a comment)

  • Flag the response

  • Start an F-Tag, Suggestion or Kaizen

  • Notify someone

A question can have several rules. Use Require evidence on critical steps.

A critical answer that starts a Kaizen needs a Kaizen type and methodology to be set up in Kaizen settings first.

Step 5: Save the template

Click Save, or Save & Publish to publish your changes and choose the language.

Good to know

  • Scoring: for audits you can give points per answer, see a total score, and set a pass/fail threshold.

  • Drag the six-dot handle on a question card to reorder questions. The right-hand pane shows a live phone preview of the form.

  • Flagged and critical responses appear in the template's Submissions and Reporting tabs in Lean Creator.
