Add questions, the building blocks of a template, to pages or to sections inside a page.

Each question has three main components:

  1. Question Field

  2. Response/Answer Field

  3. Response Properties

Enter the question

1. Open the Lean Creator window by creating a new template or opening an existing one.

2. In the question card, enter the Question. This is a text field for the main content: a question, an instruction or a text input, depending on the response required.

In this example, the question text is "Sample Question 1".

Choose the response type

3. Choose a type from the Response dropdown. It offers a variety of ways to answer and collect data.

Once you choose a response type, the response options update so you can tailor them to the question. The response options are just below the question field.

There are three main response options:

  • Required: marks the question as mandatory. The report can't be submitted if a required question isn't answered.

  • Response Properties: settings for the selected response type. For example, for a multiple-choice question, this is where you set the choices.

  • Add Rule: adds an action that is triggered when a certain response is recorded.

The Add Rule property is available for some of the response types only.

Response types

The available response types are:

  • Assignment (input: drag & drop box; Add Rule not available)

  • Date & Time

  • Drag & Drop

  • Multiple Choice Response

  • Numbers Field

  • Text Field

  • Signature

  • Slider

  • Visual Instruction

  • True or False

  • Checkbox

  • Rating

  • Pillar

  • Department

  • Line

  • Workstation

  • Asset

  • Process

  • User

  • Shift

Set the response properties

Once you choose a response type, set its response properties.

4. Choose whether the response is mandatory by using the Required field.

5. Set up the Add Rule property, if the response type supports it.
