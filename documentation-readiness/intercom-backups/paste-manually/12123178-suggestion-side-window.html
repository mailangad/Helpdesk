The suggestion side window shows a summary of a suggestion in 8 sections. Each section can be collapsed or expanded, and the window scrolls to fit them all.

To learn how to open the side window, see How to open a Suggestion after creation.

Sections of the side window

Section

Description

Labels

Add labels to your suggestion so it is easier to find and group.

Details

Shows the information entered when the suggestion was created.

Required Approver

Choose a user with authority in the related area to approve the suggestion.

Implementor

Choose a user with authority in the related area to implement the suggestion.

Problem Description

A rich text editor to describe why the suggestion was created and the problem it addresses.

Recommended Suggestion

A rich text editor to describe the recommended solution to the problem raised.

Attachment

A drag-and-drop box to attach files to the suggestion.

Activity

Records the activity on the suggestion, such as comments and changes, as it moves through feedback and implementation.

Tip

The detail view shows the same information in a larger layout, which is easier to work with when a suggestion has a lot of detail.

Good to know

Lean AI helps you write and review suggestions. It can rephrase your text and adjust its tone, and you can use speech-to-text to dictate instead of typing (Spanish is not supported for speech-to-text yet). When you view a suggestion, Lean AI recommends a Status and Priority.

A Translate button on a suggestion translates it inline. Turn off your browser's automatic translation, because it conflicts with the app.
