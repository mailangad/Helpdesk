As we know Kaizen means continuous improvement, after the creation of a kaizen it follows a systematic phase wise process, progressing from one stage to the next until it reaches its final goal.

The Kaizen module in Lean Suite provides various options and features to track and move a Kaizen ahead thereby following it’s stepwise/phase-wise approach as per the Kaizen Methodology.

To learn about these options & features we need to open up our created Kaizen by searching through the database.
