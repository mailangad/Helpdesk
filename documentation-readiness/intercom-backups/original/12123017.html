Step 1

Click on the Show Fields option in top right corner of the Suggestion window.

Step 2

The Suggestions Fields Management window will show up.

The window will have 5 columns.

Column 1

Order

Allows you to reorder the fields.

Column 2

Show/Hide

This column will enable you to choose which fields are to be shown or hidden to collect data about the Suggestion being created.

Column 3

Fields

This column will list all the available fields to choose from for entering information while creating a Suggestion.

Column 4

View Value

This fields allows you to give a value/name to a particular field other than the default name.

Column 5

Required?

Depending upon the type/purpose of the Suggestion being created, some fields will be of mandatory nature to require efficient data collection for the Suggestion. This column will let you choose the fields that you wish to make mandatory while creating a certain type of Suggestion to help in efficient implementation.

After you have made the appropriate choices for the fields related to the Suggestion in questions, click on Apply on the bottom right to apply the new settings to the Create Suggestion Window.

Step 3

Now you can fill information in the new visible fields and submit your Suggestion!

Congratulations, you have successfully added/edited fields while creating a new Suggestion.
