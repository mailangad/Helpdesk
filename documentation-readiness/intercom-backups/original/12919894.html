The Lean Creator dashboard is the central space that displays all the created templates inside a facility. This dashboard is a simple interface aimed at the necessary functions post template creation. The majority functions of the Lean Creator module are focused on the creation of new templates which happens through the Lean Creator Window.

Let's quickly summarize the dashboard before we move on to the main part i.e. the Lean Creator Window as mentioned above!

The Lean Creator Dashboard enables us to:

  1. View & Edit Templates

  2. Export Templates

  3. Search and filter the templates database

  4. Create New Templates
