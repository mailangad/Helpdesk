The F-Tag detail window displays information in a elaborated manner with 3 different fields that are displayed at the same time.

The F-Tag detail view has 3 fields:

Field 1

Implementation Field

The implementation field which has the name of the F-Tag as its heading, has options that help proceeding a F-Tag during implementation and also attach information to a F-Tag in various forms to help the process better.

Field 2

Details Field

This is the right-side panel on the F-Tag detail view dashboard.

The information field contains, displays and provides editing option to the information that a F-Tag contains which was entered while creating it.

Field 3

Activity Field

This is located just below the Implementation section.

This is a smaller field as compared to others. This records the activity as a F-Tag proceeds like comments, history etc. It may also be thought as a documentation field which records the inputs, changes and idea exchange by users pertaining to one F-Tag during the period of its process.

Useful Facts!

A user can choose to open either the side window or F-Tag detail view based on his/her preference while editing or augmenting a F-Tag.

The F-Tag detail view is exactly similar to the side window in terms of information.

The only difference between the two is that the side window shows all information in a smaller scrollable area while the detail view opens it up in a bigger area making it easier to see all information at once!
