LMS Reports, the last option in the parent menu of LMS System is the analytical section which houses record of training in a workspace.

The data in Reports section shows training time by different pillars in a workspace and also course feedback by individual courses!

This is what the reports section looks like:

The Reports section has two main subsections:

Overview

This section as the name suggests provided a high level overview of the Learning System Performance and data in a workspace.

A user can view:

  • Pillar Training (in mins) - Number of training minutes each pillar in the workspace has.

  • Number of Courses

  • Number of Instructors

  • Number of Trainees

Tips & Tricks

Click on any pillar from the table in Overview section to see the courses details inside it!

A side window opens up listing the courses inside the pillar.

The courses can be further expanded from the drop-down arrow at the end of course name.

The drop-down shows the instructors and trainees in that particular course

Course Analytics

This section analyzes a particular course and provide an option to compare quizzes as well!

Tips & Tricks

You can choose which course data you wish to see from the drop-down menu under the Course Analytics button.

Note that only published courses from the course catalog are available to choose!

Useful Facts!

The Course Analytics section has a feature that lets you compare two quizzes to get a better overlook at the learning atmosphere in a workspace!

Go to the bottom of the manual to learn more about it!
