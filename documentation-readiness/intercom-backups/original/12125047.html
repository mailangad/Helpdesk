Tag Settings inside the F-Tag Module provide various configuration options to set up how the F-Tags will be handled inside a workspace.

The tag settings are present in the Parent menu as the last option.

This is what the Tag Settings Dashboard looks like.

There are three main sections that house the settings:

General Configurations

Allows you to set User Re-Assignments

Default Assignee

Allows you to add/edit Default Assignees

Settings

Allows you to edit due date, issues/sub-issues, priority, trade types, and tag labels.

All of these settings collectively will help configure the F-Tag System inside your workspace!

These are the same settings that are present as fields while creating a new F-Tag
