Step 1

Log into your Lean Suite Account and navigate to the Lean Creator Dashboard by clicking on the Lean Creator button from the home page.

Need Help?

Step 2

Navigate to the top right corner of the dashboard and click on the Create Template button.

Step 3

A Create New Template window will open up with various input fields for creating the a template.


This window collects the basic initial details for the template before moving to the Main template window.

The four main fields in the window collect various information based on how and where the template will be used:

Template Name

Allows you to assign a name for the template.

Pillar

Allows you to assign a pillar to the template

Template type

Allows you to assign a type to the template.

There are 7 different types of templates available. Each type serves a different function. The function of each type is easily understandable from their name:

  1. Assessment/Skill Matrix

  2. Audit

  3. Inspection

  4. Kaizen

  5. Quiz

  6. Survey

  7. Other

The core of the template is made of questions and various ways of responding to that questions which ultimately helps in collection data. The template type allows to label or tag a template making it easy to choose and assign it for a particular task.

Access Permission

A template can be used inside a one facility or if needed can be shared into the workspace as well.

The access permission field allows you to make the template private or public according to the need.

There could be certain tasks/activates related to a particular facility only. The templates of such activities can be made private while some tasks activities that are worthy of sharing as workflows or standard practices can be made public. These templates are available to clone and be used in many ways.

We will see this connection inside the Daily Standard Work System.

Once you have entered the desired data click on the create button located in the top right corner.

Step 4

Once you click create, a new Lean Creator Window will open up.

This is the main space, the Lean Creator Window where the template is created with all its questions, response types, properties and values.

Lean Creator Window

Since a template creation can take a longer time, many a times more than one sitting, the window allows you to save the template you are working on as a draft.

You can visit the template again from the dashboard and continue editing or making changes as per your need!

Now that we know how to create a new template, let's move ahead and dive into the Lean Creator Window and learn about its features and components which will ultimately allow us to create useful templates to be used in our facility!
