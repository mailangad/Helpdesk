The Best Practice side window displays information in a summarized manner with 5 different fields that are collapsible & expandable thereby making the whole window scrollable owing to the different size it may have.

The different fields in a side window are as follows:

  • Details

Displays information entered while creating a Best Practice.

  • Sections

Displays Phases inside a Best Practice.

Useful Fact!

The number phases displayed in this section is the same as the phases of the methodology a Best Practice has.

  • URL Attach

This field is not collapsible but stays active. It let’ a user attach a relevant web address with a description to a Best Practice.

  • Attachment

This is a drag & drop box which let’s you attach further items to a Best Practice.

  • Activity

This records the activity as a Best Practice proceeds in implementation
