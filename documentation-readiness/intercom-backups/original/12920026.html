When we create a new KPI we can setup how to input data into the KPI after creation. The last section Source provides us 4 different ways to input data.

We can either input it through google sheets, excel, through a LeanSuite module or manually!

In this instruction we will focus on how to input data manually into the KPI since all the other available ways are automatically updated!

Step 1

Navigate to the KPI Dashboard from the home page.

Step 2

Click on the KPI you wish to input data into manually.

A side overlay window will open up showing the details of the KPI.

Navigate to the top options and click on Input Value.

Step 3

A new KPI input window will open up allowing you to enter data through various fields available.

You can choose the date range on the top right corner for entering data for a particular time period.

Click on Save at the bottom right corner when you are finished.

Congratulations! We have successfully learned how to input data manually into a KPI.
