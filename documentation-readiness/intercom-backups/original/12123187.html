Step 1

Log into you Lean Suite Account.

Need Help?

Step 2

Go to the Suggestion Campaign Dashboard by clicking on the Campaigns button in the parent menu on the home page.

Step 3

Click on the + Create New Campaign button located on the top center of the page.

Suggestion Campaign Dashboard

Step 3

A new Create a Campaign window will open up with 7 options/fields to collect information about the campaign being created.

This is the cover image for the campaign. It can be clicked by camera (depending upon device) or chosen from a device

It is optional in nature.

Organizer

This field automatically picks a user’s name as the organizer.

Campaign Name

Assigns a name to the campaign.

Start Date

Assigns the start date of the campaign.

End Date

Assigns the end date of the campaign.

Custom Points

This field lets you assign points gained by a user for every suggestion submitted into the campaign.

Description

This field lets you enter any detailed description or information to the campaign.

Useful Tips!

A campaign is run in between a period of time. A company may plan to acquire suggestions from its employees pertaining to a certain problem in a timely manner and then move to implement the best solutions. The time frame can be used to solve problems quickly!

Enter the information as required.

Step 4

Once the fields have information the Create Campaign button in the bottom right portion of the window will become active (Blue).

Click on the Create Campaign button to finish the process!

The new campaign will show up at the end of the list with its own Campaign Card!

Useful Tips!

A Campaign card is simply a small window that displays all the information of a campaign, the same which is entered while creating a new one!

It includes the cover image, name, ID date range, number of submitted suggestions, editing tools and most importantly the Submit Suggestion Button.

Congratulations! You have successfully created a new campaign to welcome suggestions from employees in your workspace!
