We know that a Kaizen follows a phase/stage wise process of implementation. How a kaizen is advanced into further stages is dictated by a workflow. A workflow is attached to a kaizen upon its creation and as certain requirements set in place by the workflow keep getting fulfilled, the Kaizen keeps progressing until its completion.

Step 1

Useful Facts!

A user can create see the workflow attached to a kaizen both in side window and detail view.

Open the Kaizen in which you wish to see the attached workflow.

Smart Connections

A workflow can be designed based on what processes & permissions need to be completed before a phase in kaizen is moved to the next.

The workflow editor allows the creation of rules & transitions that help in governing and approving the set criteria for both phase-wise ultimately the kaizen.
