Step 1

Navigate to the KPI dashboard from the home screen by clicking on the KPI button.

Step 2

Click the KPI you want to view data for.

A new overlay window will open up showing the details of the KPI.

Step 3

Scroll down to the Recent Trends option and click on expand button located right next to the View All option.

A new overlay window will open up with the details and data entered in the KPI.

Here you can select the date range, type of data, type or chart and other options.

Congratulations! We have successfully covered how to view data from an existing KPI!
