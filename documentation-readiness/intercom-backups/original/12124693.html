https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4673070

Step 3

Navigate to the top right corner of the window.

There are two Excel Icons present:

First Option: User Competencies Report

This option exports a file containing the Competency (Original, Current & Requires) for all employees inside a facility.

Second Option: Export

This option simply exports the competency details of the search results being shown in the reports dashboard of the selected section.

Useful Facts!

The Reports Section has two different sub-sections; Competency & Statistics.

The two export options mentioned above are common to both the sub-sections, but the second option will export data based on which section is selected at the time!

Step 4

Choose and click on the sub-section and the type of data you wish to export.

Use the second excel icon to export section wise data and the first excel icon to export all users competency data!

A Save As dialogue will open up allowing you to download the export results!

Congratulations! We have successfully learned how to export data from the Reports Section in Skill matrix!
