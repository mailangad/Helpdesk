NEW FEATURES

Kaizen Module Improvements

  • Timeline / Gantt Chart View: Launched a new visual timeline for Kaizen projects (This provides a clear, high-level roadmap of project schedules and milestones).

  • Delay Tracking: The dashboard now displays the number of days a project is delayed compared to its original due date (This helps managers identify and address bottlenecks immediately).

  • Delay Management Reporting: Added an Excel export option for Delay Management data (This allows for offline analysis of project timelines and performance trends).

  • In-line Label Management: Labels can now be viewed and edited directly from the Kaizen Quick View and Details pages (This streamlines the process of categorizing projects without navigating away).

  • Clickable Project IDs: Project IDs within Gap Planning are now interactive links (This enables faster navigation between planning and project execution).

Reporting & Dashboard Enhancements

  • MTD (Month-to-Date) Default Filter: A new MTD filter is now available and applied by default on dashboards (This ensures you see the most relevant current-month data immediately upon loading).

  • Default YTD for Suggestions: Suggestion reporting now automatically applies a Year-to-Date filter on page load (This provides a consistent starting point for performance tracking).

  • Manual Refresh Options: Added refresh icons to Custom Dashboards and Lean Charts (This allows for instant data updates without a full page reload).

  • QA Navigation: Added direct links for QA Dashboard and QA Settings in the side navigation menu (This provides quicker access to Quality Assurance features).

Lean Studio & Gap Planning

  • Lean Studio Quick Access: You can now view KPI Quick Views, insert data points, and create documents directly from Lean Studio charts (This connects your data analysis directly to actionable tasks).

  • Integrated Gap Planning: The system now fetches and displays active Kaizen projects alongside courses to close skill gaps (This provides a holistic view of how projects and training work together to improve competency).

  • Improved Planning UI: Implemented an accordion layout with "Expand/Collapse All" functionality (This makes managing complex gap plans much more organized).

User Experience (UX) & Lean Creator

  • Lean Creator Workflow: After saving or publishing a template, users are now prompted to either schedule it immediately or leave the editor (This ensures a seamless transition from building a template to deploying it).

  • Real-time Floor Plan Updates: Newly created tags now appear instantly on the Floor Plan without requiring a page refresh (This provides immediate visual feedback for shop-floor activity).

  • DSW UI Refinement: Improved the checkbox UI and navigation button alignment within the Daily Standard Work module (This ensures a cleaner, more accessible interface for mobile and desktop users).
