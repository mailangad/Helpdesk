Cloning an F-Tag is the process to duplicate an existing F-Tag to raise the issue again.

In real life scenarios there might be situations where the resolved issue might need to be reopened because it may not have been properly or fully handled. In such situations rather than creating a new F-Tag, we can Clone the related F-Tag and fasten the process!

Step 1

Log into your Lean Suite Account with your credentials.

Step 2

Open the F-Tag you wish to Clone in side window or detail view.

We will open the F-Tag in side window for the purpose of this instruction.

Step 3

Navigate to the clone icon from the buttons in the top bar.

Step 4

Since the tag is being cloned it corresponds to a new tag being created, similar to the one that is being cloned.

Therefore, the Create New Tag window will open up. It is the same window as the one while creating a new tag.

Enter or change the information as per requirement for the new cloned tag and click on Create on the top right corner when you’re done!
