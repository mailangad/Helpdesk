Step 1

Log into your Lean Suite Account

Need Help?

Step 2

Navigate to the top right corner of the screen and cloc on Create New from the master navigation menu.

Select KPI from the drop down menu.

Step 3

A new Create KPI window will open up

The window has two main parts:

Input fields at the left side

This is where the main data to create a new KPI is entered.

Navigation outline on the right side

This window allows us to navigate back and forth to different sections of the create KPI window.

Step 4

The creation of a KPI is done through 5 sections that collect different types of data.

KPI Basics

In this section we input the KPI basic properties such as name, pillar, a description etc.

Advanced Details

This section allows us to enter more details such as formulas, direction, thresholds etc.

Frequency

Since KPI needs to be fed data and values to properly function, the frequency section let's us define the frequency and start end date for the KPI.

Access & Visibility

This section allows us to assign the KPI to a user who will be responsible for updating the KPI. It also allows us to set the visibility, whether the KPI is facility wide, private of for a certain group of users.

Source

Data has to be input into one section before moving on to the next. When one section is finished, the right-side navigation window shows a green tick mark indication that the next section is now available to edit.

Enter the data into the section one by one and make sure you click on Save & Next to move on to the next section.

Once you are done with entering data into all sections, click on Publish to make the KPI live and ready to input data!
