The Lean Creator window is the main space where a template takes shape. The window houses options and functions for creating questions, responses and the structure of a template that aims at collecting information, performing tasks and other activities efficiently while documenting the processes attached to the template.

This is what a typical Lean Creator Window looks like.

The window has three major components:

  • Navigation bar : The navigation bar includes the major functions such as the status of the template, saving and publishing options and exiting the creator window.

  • Creator Window : This is where the questions and responses are created and their properties are edited as per requirements.

  • Preview Window : This window simply shows the preview of a question allowing us to view and edit in real time from the perspective of the user who will be assigned the template.

In conclusion, the creator window allows us to input the question and response details while the preview window shows us a preview of the final result with the navigation window allowing us to save or publish the template.
