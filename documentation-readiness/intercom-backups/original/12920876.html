The overview dashboard is the central space where all the details of the activities inside a facility can be seen and navigated from. It's the first option int he parent menu and opens up when you navigate to the DSW System from the Home page.

This is what a typical DSW dashboard looks like:

Let's take a look at the building blocks of the DSW System!

There are majorly 5 parts/block of the overview dashboard:

  1. Activities Bar

  2. Activities Type Bar

  3. Status Window

  4. Monthly Chart

  5. Calender View

Activities Bar

Located on the top left part, this bar helps you choose which activities you wish to see.

Once a type is chosen the Status Window changes showing the activities from the category chosen.

Activities Type Bar

Once the activity category is chosen, the next bar helps you choose which type of activity you wish to see.

The types of activities are similar to the template types available in Lena Creator !

Similar to the previous bar, the changes are reflected in the Status Window.

You can either choose to view All or a particular type of activity.

Status Window

This is the main window where the activities are displayed.

There are four mains sections namely In Progress, Upcoming, Overdue & Submitted.

As we learned above the Status Window updates simultaneously with the choices made in the Activity and Activities Type bar.

The Status window allows you to Start an activity or view a report for an activity from the Submitted section.

Monthly Chart

A visual aid, the chart section shows This Month's Breakdown of the type of activities submitted in the facility.

It provides a high level summary of the work in the Facility on a monthly basis.

You can collapse the section using the arrow in the top right corner.

Calender View

Similar to the chart the calender view is also a visual aid that shows the templates/activities in a months wise breakdown making it easy to get a high level idea of the facility progress.

All the 5 sections combined provide a holistic summary of the activities in a facility.
