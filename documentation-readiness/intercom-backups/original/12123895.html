Step 3

An Import window will open up with various options.

There are two main stages of importing defects:

Stage 1: Upload File

Stage 2: Field Mapping

As the name suggests, we upload the file with defects.

Field mapping is the process of aligning each column in your data file with the corresponding fields in a Cost Management. This ensures accurate data interpretation and processing by the matrix.

For instance, mapping a "Cost" column in your file to the tool's "Cost" field enables Cost Management to recognize and handle these entries as cost values.

Stage 1: Upload File

Step 3.1

Before uploading the file you need to select the type of defects.

Select the type of defects from the two options above the Drag & Drop Box.

There are two types of defects:

Stage 1

Stage 1 defects are uploaded directly into the database & are available to be analyzed.

Stage 2

Stage 2 defects allow you to directly create a loss tree from the data being uploaded.

When you select Stage 2, enter the title of the Loss Tree and the Start and End Date before proceeding to upload the file!

Step 3.2

Drag the file to be uploaded or use the Browse option to upload the file.

Useful Facts!

You can upload CSV, XLS and XLSX files and the maximum file size should be 200 megabytes.

Cost Management allows one file to be uploaded and mapped at a time.

Once the file is uploaded, it will appear in the list below.

Tips & Tricks

In case you upload a wrong file, use the garbage bin icon on the far right to delete and upload the file again!

Step 4

Once the file is uploaded, click on Next to proceed to the Stage 2.

Stage 2: Field Mapping

Step 5

When you are finished with the field mapping process, click on Import in the bottom right corner.

Useful Facts!

The Major stages i.e. Upload File & Field Mapping are accessible at any point in the process, you can click on them to access the stage.

The data will be imported, and a small status bar will show up in the bottom right end of the screen.

Tips & Tricks!

You can click on the arrow besides the cross mark in the status bar to view the details of the uploaded file!
