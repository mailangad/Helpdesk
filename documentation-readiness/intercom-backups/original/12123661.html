When a Kaizen is created, it collects information through various fields as per requirement.

This information is stored in all kaizens, available to see through the dashboard.

After a Kaizen is submitted into the database, the information entered can be edited according to need as a kaizen proceeds further.

There are two scope in which the information can be edited:

Properties Information

Information entered while creating a new Kaizen.

This scope covers the integral information that forms a Kaizen, ex. type, loss type, due date, start date, methodology etc.
