The Kanban Board, second option in the parent menu of the DSW system is a visual aid that displays the activities in a facility in a kanban format.

This is what a typical Kanban Board section looks like:

There are two building blocks of the Kanban Board Section:

Activities Bar

This bar allows you to chose the category of the activities you wish to see in the board.

Swimlanes

These are four columns/swimlanes scrollable until all activities are show.

The activities are shown in Overdue, In Progress, Upcoming and Submitted Columns!

You can directly start an activity as well as view a report from the Kanban Board!
