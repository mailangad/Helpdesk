When a Best Practice is created, it collects information through various fields as per requirement.

This information is stored in all Best Practices, available to see through the dashboard.

After a Best Practice is submitted into the database, the information entered can be edited according to need as a Best Practice proceeds further.

Useful Tips!

The properties information inside a best practice is only editable is the editable state of the best practice is NotApproved.

Once a best practice is approved, it points to the fact that the information inside the best practice is effective and would yeild the same results when applied to that particular department, pillar or process. Therefore, after approval a user cannot edit a best practice’s properties information.

The attached information, however, can be edited!

The state of a best practice can be known in the dashboard.

Useful Tips!

Before you go ahead and edit information in a Best Practice, make sure it is not in the Approved state!

There are two scopes in which the information can be edited:

Properties Information

Information entered while creating a new Best Practice.

This scope covers the fields which are used to collect information when creating a best practice.
