This release introduces powerful AI-driven features for the Suggestion module, significant reporting and assignment upgrades for LMS, and numerous user experience enhancements across the platform.

NEW FEATURES

Kaizen Module

  • You can now save custom views with applied filters on the Kaizen dashboard (This allows you to quickly access specific datasets without reapplying filters each time).

  • Users can now add "Project Source" to "Workflow Mapping" in Kaizen (This provides added customization based on the origin of each improvement project).

Suggestion

  • The Lean AI module now recommends "Status" and "Priority" values when viewing a suggestion (This streamlines the review and classification process).

  • Enabled two-way linking between Suggestions and Kaizen documents (This creates a seamless connection for tracking ideas from suggestion to project implementation).

LMS & Reporting

  • Added "Year" and "Completed On" filters to the LMS Reporting Overview (This provides more granular control for analyzing training data).

  • Added the ability to assign courses directly to one or more user roles (This simplifies course enrollment for entire teams or departments).

  • Introduced a new "Monthly Pillar Training Summary" report (This chart visualizes total training duration vs. the number of trainees for each Pillar). - Pending | Under testing

F-Tag Module / Floor Plan

  • You can now drag and drop pins on the floor plan (This makes it easy to adjust or reposition items to reflect their correct locations).

  • The size of the dots representing tags on the floor plan can now be configured (This provides better visual control over your layout).

  • Introduced "Tag Labels" for enhanced organization (This allows you to add, update, and filter by custom labels on the create and view pages).

  • Improved the Tag Module's input field configuration for better performance and maintainability.

User Profile & Management

  • Users with edit permissions can now update the "Original Level" directly from the radar chart (This provides more flexibility for managing skill levels).

  • Added pagination for the tool count on the radar chart (This improves readability when many tools are present).

  • You can now update your own username from the user update page (This gives you more control over your profile information).

General User Experience

  • Redesigned the Login and Authentication user interface (This provides a smoother, more modern, and intuitive login experience).

  • The cursor now automatically focuses on the search input field when opening a user filter (This small update speeds up your workflow by letting you type immediately).

  • Images added to the description text editor are now automatically included in the main "Attachments" section (This ensures all related files are saved in one central location).

BUG FIXES

Kaizen & Reporting

  • Fixed reporting inaccuracies on the Wall of Fame (This ensures all savings data is calculated and displayed correctly).

  • Enhanced the Wall of Fame chart to correctly sort and display data when table column headers are clicked.
