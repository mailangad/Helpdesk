As we learned the instructor panel allows the creation and administration of knowledge material inside a workspace, let’s move ahead and learn about the usage aspects of the Instructor Panel via a typical high-level workflow which then will be detailed out as we proceed.

Looking back at the main aim of the Learning Management System, a typical task chain for an instructor who is administering a course inside a workspace would proceed as follows:

Step 1

Create a Course on a particular topic eg. security training at manufacturing site.

Step 2

Create evaluation procedures to test the knowledge uptake of the training i.e. creating quizzes.

Step 3

Marking the set evaluation procedures to ensure a trainee is well versed with the knowledge and is ready to implement it in real-life scenarios.

The above workflow concludes to two main aspects of LMS i.e. a Course and a Quiz.

As we move forward we will learn about the LMS via learning course creation and quiz integration!

All of these steps above have their sub-details and options as one proceeds through the tasks.

In conclusion, an instructor uses the panel to create courses and their subsequent quizzes along with performing evaluations as and when required!
