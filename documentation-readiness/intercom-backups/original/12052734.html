We are excited to announce a major release packed with new features and enhancements across the LeanSuite platform. This update is designed to improve reporting, streamline workflows, and provide deeper insights into your continuous improvement efforts.

NEW FEATURES

User Profile & Dashboards

  • Added a paginated "Tool Name" display to the Radar Chart (This improves readability on complex charts).

  • Made "Original Level" input fields non-editable on the user profile (This enhances data integrity by protecting historical records).

  • Introduced new Stat Cards on the main App Dashboard: Worked On, Approval, Assigned to Me, Overdue, and Upcoming (This provides a quick overview of your key responsibilities).

  • Enhanced the Wall of Fame chart to display a paginated list when multiple users have identical savings (This ensures every contributor is recognized).

Kaizen Module

  • Enabled automated email and in-app notifications for Due Date Extension Requests (This ensures approvers are notified promptly).

  • Users can now add and track multiple KPIs within a single Kaizen's Target Section (This allows for a more comprehensive view of a project's impact).

  • Implemented an Active/Inactive status for tracking Savings Info in the Result Section (This gives you direct control over which savings are reflected in results).

  • Added a "Year Filter" to the Kaizen Dashboard (This improves data range selection for historical analysis).

  • Added an Excel Export feature to the Kaizen Team View page (This simplifies offline data analysis of team contributions).

  • Set the default filter on the Approval Dashboard to "Open" (This helps approvers immediately see items requiring their attention).

  • Enhanced the Due Date Extension Excel exports to include "Revised Due Date Reason" and "Kaizen Project ID" columns (This provides more context for project timeline changes).

Reporting & Data Management

  • Added a "Saving Type" filter to the Cost Management Dashboard (This allows for more granular data segmentation).

  • Added a "Lead/Skill Trade" column to the BP Dashboard data table (This provides an additional layer of detail for reporting).

  • Added a "Facility Filter" to LMS reports (This enables better location-based filtering of training data).

  • Added a "Submitted On" column to the Suggestion Excel Export (This allows you to capture the precise submission date for each suggestion).

Lean Creator

  • Introduced a dedicated "Lean Creator" permission (This supports controlled template editing and deletion actions).

BUG FIXES

Kaizen Module

  • Fixed an issue where Workstation information was not appearing on the expanded Kaizen view (This ensures all relevant project data is consistently displayed).

Mobile App

  • Resolved an issue that prevented users from properly taking photos using their device's camera (This restores full camera functionality within the app).
