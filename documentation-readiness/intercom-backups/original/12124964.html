As we know Best Practice is a kaizen in different form, after the creation of a Best Practice it follows a systematic phase wise process, progressing from one stage to the next until it reaches its final goal.

One best practice in implementation is a kaizen, but when a problem is frequent, the most effective kaizen forms the best practice kaizen for that particular problem.

The Best Practice module in Lean Suite provides various options and features to track and move a Best Practice ahead thereby following it’s stepwise/phase-wise approach as per a kaizen methodology attached to it.

To learn about these options & features we need to open up our created Best Practice by searching through the database.
