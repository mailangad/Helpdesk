The Daily Standard Work System is the central space where you can assign activities/tasks to users as well as see the tasks assigned to you.

Let's go ahead and see how to start a task that's assigned to you in Daily Standard Work!

Step 1

Navigate to the Daily Standard Work System from the home page.

You can begin the task assigned to you in two ways:

  1. Overview Dashboard

  2. Kanban Board

Step 2

2.1 Starting Activity through Overview Dashboard

Navigate to the top menu bar and click on My Activities option.

You can further select the activity you wish to start from the options located just below the main bar.

Once selected, choose from In Progress, Upcoming and Overdue options to start an activity.

Step 3

Next, choose and click on Start option under the Action column for the activity you wish to begin.

A new window will open up with a template created in the Lean Creator System.

Step 4

Fill in the details as required and click on the Submit button located in the bottom right corner of the last page.

Once submitted, it will become available in the Submitted column as a report available to view.

Congratulations! We have successfully learned how to start and submit an activity assigned to you!
