The parent menu of the module has the main options that are displayed in the dashboard.

To reach the Skill Matrix parent menu, select the Skill Matrix option on the account home page.

The main parent menu in Skill Matrix Module (Dark blue background) has three main options:

Parent Menu

Skill Matrix Module Parent Menu Options:

  • Team Dashboard: Takes you to the Skill Matrix dashboard.

  • Reports: Takes you to the reports (analytics) section.

  • User Profile: Takes you to your profile inside Skill Matrix.

All of the options mentioned above, when selected expand respectively in the right-side panel (white background) which provides details and further options for a Skill Matrix/Issue Tracker.

Right Side Expanded Panel

(Dashboard)

The right-side panel can be imagined as the display in a control center where the information is displayed when the control buttons (Left Menu) are activated.

The right-side panel opens simultaneously when any option is selected from the left parent menu. All the detailed data about a Skill Matrix/Issue Tracker from its information to editing capabilities are housed in the right-side expanded panel.

This panel stays connected to the left side panel and helps the user add, edit, navigate and process a Skill Matrix/Issue Tracker.
