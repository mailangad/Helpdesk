The procedure to add the above information/data is different depending upon the user preference.

Therefore, we will learn how to add a file using both side window & detail view!

Choose what you wish to learn!

How to add a file using Side Window.

Step 1

Click on the suggestion you want to add a file to open the overlay side window.

Scroll down to the Attachments section.

Step 2

Click anywhere inside the box or simply drag and drop a file into the box.

Once you have selected a file to be attached or dragged dropped the file into the box, it will show up in a list manner right below the box.

You can use the red garbage bin option on the right end of the file name to remove the file.

How to add a file using Detail View.

Step 1

Open the suggestion you want to add a file to in the detail view window.

Click on the Attach button on the top and select Attach option from the drop down list.

Step 2

A browse window will open up allowing you to choose a file from your system.

Once selected it will show in a list manner below the attachment box.

Scroll down to view the added file.

Congratulations! You have successfully learned how to add a file to your Suggestion!
