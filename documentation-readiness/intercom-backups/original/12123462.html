Step 1

Once the Add New window opens up, under the already created Kaizen Type (“Quick Kaizen” in example picture); click on the Add Kaizen Methodology option nested at the bottom. (Scroll down if needed).

Step 2

A new information box will show up where you can enter the new methodology that you want to create. (In this case “Sample New Methodology” in picture).

Once you have entered the name, go to the right of the box and click on Create.

When you type in the name of your methodology, if a similar name/methodology has already been created in the database, it will show up in the suggestions list (Currently showing “No Item Found”)

The No Items Found will indicate that there is no such name and a new methodology with the name you entered can be created from scratch.

The next step will guide you towards the further creation process.

Step 3

Once the system checks that there are no existing/overlapping names or methodologies, it will direct you towards a new Add Methodology window.

A Kaizen Methodology follows a phase-wise process to attain a desired goal.

The Add Methodology window let’s you create phases for the new methodology you are creating.

Enter the name of the details and phases required as per need.

Click on the “+”Plus Sign to add a new phase, and “- “ Minus sign to delete an already created phase inside a methodology.

Once you’re done, click on Save on the bottom right corner.

A message, Methodology Added Successfully will show up on the top notification area.

A new methodology with the name you entered will show up under the Kaizen type you selected.

Congratulations, you have successfully added a new methodology in a kaizen type. 😀

The Add New Window native to both Kaizen type and Methodology provides options to edit the detail settings of the methodologies present.

These settings relate to the time (phases of methodology) and if a methodology needs to be made default.

Learn about how to edit the methodologies detail.
