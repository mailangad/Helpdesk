How to create a new F-Tag?

Step 1

Click on the Show Fields option in top right corner of the F-Tag window.

Step 2

The F-Tag Fields Management window will show up.

The window will have five columns.

Column 1

Order

Allows you to reorder the fields.

Column 2

Show/Hide

This column will enable you to choose which fields are to be shown or hidden to collect data about the F-Tag being created.

Column 3

Fields

This column will list all the available fields to choose from for entering information while creating a F-Tag.

Column 4

View Value

This fields allows you to give a value/name to a particular field other than the default name.

Column 5

Required?

Depending upon the type/purpose of the F-Tag being created, some fields will be of mandatory nature to require efficient data collection for the F-Tag. This column will let you choose the fields that you wish to make mandatory while creating a certain type of F-Tag to help in efficient implementation.

After you have made the appropriate choices for the fields related to the F-Tag in questions, click on Apply on the bottom right to apply the new settings to the Create F-Tag Window.

A green window with Fields Updates Successfully will show up to confirm the changes made.

Step 3

Now you can fill information in the new visible fields and submit your F-Tag!

Congratulations, you have successfully added/edited fields while creating a new F-Tag.
