F-Tag also offers the flexibility to create certain pre-confugured issues & sub-issues corresponding to the pillars inside a facility. These issues help in pinpointing the area and the problem to be resolved by the F-Tag.

Example Anchors

For example, the painting department my require frequent cleaning of their workspace regularly and in case of spills, leaks etc. In this case an issue can be created inside the database where the main issue is related to cleaning and the sub issue can define whether it is because of a spill or leak or any other accident.

These issues can be created as a part of configuring the database and can be turned active or inactive as per requirement. These issues and their sub-issues are available to attach as fields in an F-Tag while creating a new tag.

Example Anchors

Another way of using issues inside F-Tag can be to check and inspect various machines or equipment's inside a facility. When a machine or equipment requires frequent maintenance, an issue with a sub-issue detailing the part that needs to be looked at can be created inside F-Tag. This issue can be then called upon whenever there seems to be any problem or the equipment is not working properly.

With the priority attached to the issue and the pillar, the default team assigned pick up the issue at the earliest and resolve it preventing any loss in time, cost, labour, injury and many more possible outcomes of a faulty equipment!

Issues inside F-Tag not only helps in detailing the issues created but also helps in saving time by quickly calling upon the concerned assignees for taking up the task!
