The parent menu of the module has the main options that are displayed in the dashboard.

To reach the Cost Management parent menu, select the Cost Management option on the account home page.

The main parent menu in Cost Management Module (Dark blue background) has six main options:

Parent Menu

Cost Management Module Parent Menu Options:

  • Cost Management: Takes you to the Cost Management dashboard.

  • Reports: Takes you to the reports (analytics) section.

  • Import: Lets a user import Internal & External Defets.

  • Import History: Shows the imported files history over time.

  • Loss Trees: Takes you to the Loss Trees Dashboard

  • Mapping Resultant & Casual Losses: Takes you to the section for mapping the losses uploaded in Cost Module.

All of the options mentioned above, when selected expand respectively in the right-side panel (white background) which provides details and further options for a Cost Management.

Right Side Expanded Panel

(Dashboard)

The right-side panel updates as we select the option from the parent menu. The selected option is highlighted in yellow color depicting that it is active and open in the right si

The right-side panel can be imagined as the display in a control center where the information is displayed when the control buttons (Left Menu) are activated.

The right-side panel opens simultaneously when any option is selected from the left parent menu. All the detailed data about a Cost Management from its information to editing capabilities are housed in the right-side expanded panel.

This panel stays connected to the left side panel and helps the user add, edit, navigate and process a Cost Management.
