Kaizen Settings as the name suggests are module settings specific to Kaizen in Lean Suite.

As we know, the parent menu has 2 states which have Kaizen Settings as the common option.

When selected, the Kaizen Settings performs 2 simultaneous functions. Let’s go ahead and learn about them.

Function 1

This function opens up the Add New window on the right side expanded panel.

The Add New window provides editing options that are helpful while creating a Kaizen.
