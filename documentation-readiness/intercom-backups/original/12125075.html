The activity field is located at the bottom of the tag space in both the detail and side view.

The Activity Field as the name suggests records and views the activity of a F-Tag. It is the smallest section when a F-Tag is opened up.

The activity section:

  • Records or hold the activity inside a F-Tag i.e. whatever changes that take place during the progress of a F-Tag.

  • Provides a comment section for the users/employees to interact and share insights as a F-Tag proceeds.

The Activity Section has 3 sections as follows:

All

The section shows both comments & history changes all together with the latest on top.

Comments

This section shows just the comments on a F-Tag with the latest on top.

History

This section shows just the changes on a F-Tag with the latest on top.
