Every Module in Lean Suite has its own dashboard & parent menu.

The parent menu of the module has the main options that are displayed in the dashboard.

Need help?

To reach the suggestion parent menu, select the Suggestion option on the account home page.

The main parent menu in Suggestion Module (Dark blue background) has four main options:

Parent Menu

  • All Suggestions (Dashboard): Takes you to the suggestion dashboard.

  • Reports: Takes you to the reports (analytics) section.

  • Suggestion Settings: Takes you to the settings/preferences window.

  • Points:

All of the options mentioned above, when selected expand respectively in the right-side panel (white background) which provides details and further options for a suggestion.

Right Side Expanded Panel (Dashboard)

The right-side panel updates as we select the option from the parent menu. The selected option is highlighted depicting that it is active and open in the right side.

The right-side panel can be imagined as the display in a control center where the information is displayed when the control buttons (Left Menu) are activated.

All the detailed data about a suggestion from its information to editing capabilities, settings, reports are housed in the right-side expanded panel.

This panel stays connected to the left side panel and helps the user add, edit, navigate and process a suggestion.
