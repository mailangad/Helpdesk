Overview

Once a suggestion is created and is available in the database, similar to a real-life scenario, it would be analyzed by an authority to whom it may relate. If the suggestion is found useful it can be moved further for implementation to bring about the change suggested! A suggestion a can also be rejected or marked as not a suggestion if found not useful enough.

The approval has two parts:

  1. Approval

  2. Adding Approver/Implementor

Part 1: Approval Options

There are a total of 4 options available once a suggestion is submitted into the system:

Approve

Simply Approve a suggestion and proceed it further.

Approve with Feedback

Approve the suggestion and add feedback to inform the user or add feedback to make some changes that may be useful.

Reject

Simply Reject a suggestion if not found useful.

Not a Suggestion

This helps in notifying the user of the nature of a suggestion specifically when the information points towards not being a suggestion that can be analyzed or acted upon.

Part 2 : Adding Approver/Implementor.

This section is present right before the Approve button in the suggestion side window or detail view.

As the name suggests it helps in adding an approver or implementor to the suggestions proceedings.
