As the name suggests, the Instructor Panel is the central space for a user in the workspace to create and administer courses for training, security, knowledge and whatever is the requirement for a company using Lean Suite.

Useful Facts!

The user needs to have certain permissions to be able to create and administer courses.

Learn About Permissions inside Lean Suite!

Below is a breakdown of the options and field inside the Instructor Panel:

Top Bar

  • Submitted Quizzes: As the name suggests, it shows the number of submitted quizzes and also takes you to the central space where quizzes from all courses are listed and are available to view & mark!

  • Instructors : This space shows the number of instructors in a workspace and takes you to the list of instructors inside a workspace. An instructor can see all other instructors and with given permissions can add and remove an instructor in LMS!

The Top Bar Options allows an instructor to:

  • View Submitted Quizzes

  • Mark Submitted Quizzes

  • View the Instructors in a Workspace

  • Add or Remove Instructors in a Workspace.

The View Details option in both cards open up a combined “Your Tasks” dashboard for Submitted Quizzes and Instructors in LMS. This dashboard lists all the instructors and quizzes inside a database.

This is what the combined dashboard looks like:

Your Leaning Hub

This section inside the Instructor Panel displays the courses and quizzes created in the database.

:red_star: The Button with white text on blue background signifies the active button. Switch between courses/quizzes using these buttons!

This is the central place where an instructor can create and develop a course and related quizzes to administer in the workspace!

The Learning Hub Options allows an instructor to:

  • Create a Course

  • Assign a Course

  • Delete a Course

  • Create a Quiz

The Learning Hub displays a certain number of courses and quizzes only.

The View All Courses/View All Quizzes button located on the top right corners of the Learning Hub section open up the All Courses/All Quizzes dashboard where further options are available relating to both!

Useful Facts!

The All Courses/All Quizzes dashboards allow an instructor to create new courses and quizzes!
