The reports section, as the name suggests produces reports based on the submitted Best Practices by analyzing the information inside a Best Practice for example state, approach, pillars, cost etc.

The reports are statistical data that help a facility analyze how the Best Practices are being created, proceeded and concluded. By using charts and other infographic elements, the data provides a crucial insight into a facility’s workings.

The reports section in Best Practice module has three main sections:

Overview

As the name suggests this section provides an overview to the overall Best Practice module.

The data present in this section consists of:

  • Best Practice By Pillar

  • Best Practice By Status

  • Best Practice By Adoption Status

Benefit & Cost

This section provides analytical data in the form of a chart showing values of how Best Practice system is proceeding in a facility; how many Best Practices are being evaluated and approved or furthered into implementation.

Regional Overview

This section provides analytical data in the form of a various charts showing values of how Best Practices are performing in a region.

The data present in this section consists of:

  • Best Practice Count by Adoption Status by Pillar

  • Best Practice Count by Adoption Status by Facility

  • Best Practice Count by Pillar

  • Best Practice Count by Process

  • Best Practice Count by Loss Type

Useful Tips!

The Reports section in the best practice module provides dashboard like search features right on the top. This can help see analytical data filtered according to search criterion!

The process to of searching is the same as in the best practice dashboard!
