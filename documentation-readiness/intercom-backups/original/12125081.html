The Status of an F-Tag is denotes the operating process of the issue at any given time:

Open

The F-Tag has been created and is ready to be submitted to the next stage

Pending Verification

The F-Tag has been submitted into the database and is ready to be verified or acknowledged by the concerned authority.

The Verification process is done by the person who has been assigned as the assignee in the tag and involves two processes in a single stage.

Firstly, the tag is verified.

Secondly, based on the verification a decision is taken:

  • If the issue is found, it is taken action upon and therefore Marked as Complete.

  • If the issue is found as a concern of some other expert/authority or assignee then it is Sent Back, upon which it again restores to Pending Verification Status.

Overdue

An F-Tag has a due date by which is to be resolved. If the due date has passed and the issue is not resolved, the status changes to Overdue.

Close

When the issue has been resolved, an F-Tag can be marked as complete and the status changes to Close.

After creation the Status tab in the F-Tag (both side window and detail view) is an important option as it helps to move, update, inform, reassign the F-Tag inside Lean Suite.

The working of the F-Tag can be controlled and managed through the Status Tag.
