A Kaizen employs a phase-wise approach, the phases of which are derived from the methodology of the Kaizen.

Each phase carries instructions, work details, documentation tools and many more sets of data that are instrumental either in the working or documentation of the process for future references. This data inside the various phases is necessary to complete that particular phase and move on to the next.

Depending upon the type of work that the kaizen is needed for, there may be multiple phases. Each phase will require a set of instructions, information or tools necessary for implementation. This data is fed into or connected to phases via Sections.

Sections are numerous, small widget type additions into phases that serve to detail out any information that is required during Kaizen implementation!
