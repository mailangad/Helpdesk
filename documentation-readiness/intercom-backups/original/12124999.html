Step 1

Navigate to Tag Settings in the parent menu of F-Tag.

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4672899

Step 2

Select Settings from the three tabs provided on top.

Step 3

Navigate to the top right corner above the Default Due Date list.

There are to options present:

Step 3.1

Drop-Down Menu

Click on the arrow on the right and select Default Due Date View.

This will open the Default Due Date Window.

Useful Facts!

The Settings tab in F-Tag helps us set up 4 settings, two of which are set in one place while the other two have their own respective windows.

The Default Due Date & Issues share the same window.

The Priority and Trade Type have their respective windows.

Step 3.2

Create Button

Click on the Create New button after selecting the option from the drop-down menu.

This will open the Create Default Due Dates window.

Useful Facts!

The Create Button corresponds to the selected window.

When the Default Due Date Window is selected, the create button allows us to create a new default date.

When the Issues View (picture on left) allows us to create a new Issue.

Step 4

Enter the information in the Create Default Due Dates window as per requirement.

Pillar

Choose the Pillar for which you wish to create a default due date.

Priority

Choose the Priority you wish to set.

Smart Connections!

Apart from the standard priorities i.e. High, Medium & Low, another types of priorities can be set with a certain number of days required to close the issue. Follow below to learn more!

https://theleansuite.atlassian.net/wiki/spaces/KC/pages/edit-v2/188187036?draftShareId=747f3840-7a70-4ab3-bb20-9e854c0d9bbe

Days To Close

This is the most important field in the window as it allows you to set the number of days in which any issue related to the pillar selected should be resolved.

After you have added the information as required click on Save in the bottom right corner to finish the process.

A new Default Due Date will be created and added in the list. Make sure to check the list for your newly created Due date.

Congratulations! We have successfully learned how to create a new default due date!

With the creation process completed, let’s go ahead and learn how to edit a default due date in F-Tag!
