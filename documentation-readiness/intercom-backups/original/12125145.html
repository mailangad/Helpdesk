The My Learning section in LMS Module is a user specific section providing information about the Learning history and record of a user.

Tips & Tricks!

The My Learning section can be reached via the Parent Menu and also the View All button in the dashboard.

Here’s the refresher connection: https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4673023

This is what a typical My Learning Section looks like:

The section has a top bar and a bottom display section.

The top bar has three main options which when selected update the display section below:

  • All Courses: This enables the user to view all the courses they are enrolled in.

  • Wishlist: This option shows the user the courses they mark as “Wishlist” i.e. the courses they wish to complete or get enrolled in future.

  • Search Options: Located between the display section and the top menu bar, the three fields allow a user to search through the database by course name (ID & Title), course status & course type.

Tips & Tricks

The View button on the top right of the display section enables a user to switch between how the results are displayed. There are primarily two options; Table & List.
