In order to understand what “Approval Dashboard” contains, let us first understand what an approval is inside a Kaizen.

When a Kaizen is created, it has various information fields that help us collect data.

Need a refresher ?

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4672945

In these fields, you’ll find a Start Date & Due Date fields, which as their name suggests mark the start and end date of a Kaizen.

In a real world scenario their might be situations that arise causing a delay in the implementation of a Kaizen subsequently changing the due date. Since the implementation of a Kaizen requires time, planning, labor and other resources a company using lean suite may require that an approval be taken before changing the due date of a Kaizen.

This intermediate process of obtaining an approval before changing a due date helps the concerned authority granting it examine the reasons and analyze the availability of resources, time, labor etc. to make sure the delay in Kaizen is logical and possible.

Smart Connections!

While changing the due date in a Kaizen, a user needs to attach a reason for the change. This reason is then analyzed before granting an approval to change the due date.

One of the features in Kaizen Module is Revised Due Date Reasons, which helps the company/facility using Lean Suite create definite reasons based on their processes and environment.

These reasons are then available to users/employees to choose from while submitting an approval request for due date change.

At a time, a number of employees can submit a request for the change in due dates with subsequent reasons.

All these kaizens with pending approvals for due date change are listed in the Approval Dashboard.

An Approval Dashboard:

  • Lists all kaizens with pending approvals.

  • Allows you to search for a Kaizen via a Search Dates box.

  • Provides an Action button (available according to the admin rights if a user) to approve or refuse a particular kaizen.
