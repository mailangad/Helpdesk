A workspace or an industry can have multiple departments and pillars with different priorities and importance of work handled in them.

When an issue arises in a workspace it can be related to any of the departments inside the facility. Depending upon the type of facility, it is important to solve some issues sooner and quicker as compared to other less sensitive issues.

Here’s an example to understand the concept better:

A faulty screw in one of the parts of the assembly line should be resolved as soon as possible ensure further loss of time and cost.

An area inside a facility has to be cleared off to make storage stacking space for an upcoming project in two months. Since there is time for the next project to start and the faulty screw can cause the delay to go further, the above issue carries more importance than the latter.

In such cases, the configuration options inside F-Tag provide an option to det a default due date to ensure that certain issues are always given a priority and are solved withing a particular frame of time that can be set in the system.

This particular default date can be set inside the parent menu of F-Tag!

Congratulations! We have learned about the Default Due Date in F-Tag Module!
