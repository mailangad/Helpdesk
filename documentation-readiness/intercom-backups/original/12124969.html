The Best Practice detail view has 3 fields:

Field 1

Implementation Field

This field is located on the top left side and is the first section that a user starts to see.

The implementation field which has the name of the Best Practice as its heading, has many options that help proceeding a Best Practice during implementation and also attach information to a Best Practice in various forms to help the process better.

The major options present inside this field are:

Attach Button

Link Button

Workflow View

Best Practice Data Export Button

Advance to Button

Share Best Practice Button

Phases of Best Practice

Phase Sections

Add Link

Drag & Drop Box

Field 2

Details Field

This is the right-side panel on the Best Practice detail view dashboard.

The information field contains, displays the information that a Best Practice contains which was entered while creating it.

Useful Fact!

This field is actually the details in the side window in a Best Practice in a bigger view forming the right side of the Best Practice detail view.

Three of the sections inside the side window shift to the left available area making up the Best Practice detail view!

Field 3

Activity Field

This is located just below the Implementation section.

This is a smaller field as compared to others. This records the activity as a Best Practice proceeds like comments, history etc. It may also be thought as a documentation field which records the inputs, changes and idea exchange by users pertaining to one Best Practice during the period of its implementation.

Useful Facts!

A user can chose to open either the side window or Best Practice detail view based on his/her preference while editing or augmenting a Best Practice.

The Best Practice detail view is exactly similar to the side window in terms of information.

The only difference between the two is that the side window shows all information in a smaller scrollable area while the detail view open it up in a bigger area making it easier to see all information at once!
