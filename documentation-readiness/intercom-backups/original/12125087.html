This manual will focus on the first part of the course creation i.e. Adding a new Course.

Step 1

Log into your Lean Suite Account with your credentials.

Need Help?

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4672769

Step 2

Navigate to the Instructor Panel in LMS system.

Need Help?

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4673022

Step 3

Navigate to Your Learning Hub and click on View All Courses on the extreme right.

Useful Facts!

Make sure the Courses tab is selected between the Courses & Quizzes buttons in the Learning Hub.

The All Courses dashboard will open up.

Click on the Add New button on the top right of the window.

Step 4

A Create Course window will open up.

Following are the major information fields while creating a Course:

Course Code

Enter the course code.

Course Title

Enter the course title.

Course Duration (Mins)

Enter course Duration in Minutes.

Course Category

Choose a pre-existing category from the database or create one using the button.

Follow below for more instructions on creating a new course category!

Pillar

Choose the Pillar for the course.

Course Type

Choose the type of course; Online or In-Class

Course Access

Choose the Course Access; Public or Private.

Useful Facts!

A course can be made publicly available in a workspace or kept private which would require asking for access to the course.

The excerpt below focuses on how to create a new category while creating a new course.

Fill in all the information as required and proceed to click on Save on the top right corner.

A new course with the details entered will be created and green colored notification will show up confirming the creation.

This concludes the Part 1 - Adding a new Course. Go to the end of the manual to proceed to the second part!

Congratulations! We have successfully learned about the first part in the creating course process.
