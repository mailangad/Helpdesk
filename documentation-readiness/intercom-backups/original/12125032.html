Whenever an issue is raised through the F-Tag Module, based on the type of work or expertise required to resolve the issue, an employee or authority is assigned to the tag.

The person is responsible for the resolution of the issue and is called the Assignee for that particular tag.

Now, in a facility a person with a set of expertise will be assigned for similar issues. Rather than going through the process of assigning a new person for the issue a Default Assignee can be set up which makes the process more streamlined and effective.

Furthermore, the default assignee can be set for a particular issue, sub-issue, departments and various other factors which are available to set while creating a new default assignee!

A user can check the default assignees set up in the facility in the Default Assignee Window in the Tag Settings.
