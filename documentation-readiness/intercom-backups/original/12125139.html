The third option inside the LMS Parent menu is the Course Catalog.

The Course Catalog essentially is the central space where all courses available in the database for users to enroll inside a facility/workspace/plant etc. are listed.

Course Catalog is the section inside LMS through which courses are administered.

This is what the typical Course Catalog Dashboard looks like:

The Course Catalog dashboard essentially has two main sections:

  • The top bar which houses all the Search options.

  • The Display section which displays the courses in Table or Grid manner.

Search Options

A user can search the courses by:

  • Name (ID & Title)

  • Course Access

  • Pillar

  • Course Category

  • Facility

Tips & Tricks

Click on the More button to access more search filters that can be used to effectively search for courses in the catalog database!

Display Section

User can choose to alter the display section to show courses in Table or Grid.

The Display Option button is located on the top right corner of the display section.

The most important function in the display section is the Enroll Now button. This button enables the user to enroll in their selected course.

Useful Facts!

The Enroll Now button is located at different locations in the Table & Grid views.
