Once a Best Practice is created, the module gives various options of attaching information to a Best Practice which is helpful for the successful implementation of the Best Practice. This helps it follow a Best Practice phase wise approach by accepting feedback into every phase.

Step 1

Open the Best Practice you wish to attach information or data to.

You can either open a Best Practice in side window or in a detail view.

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4673092

Step 2

You can add information to a Best Practice in 4 different ways. Choose from below to learn further!

🔖Attach

Attach a file of any format.

➰Sketch

Add an explanatory sketch.

🖼️Photo

Add a photo by using device camera.

🌐Web URL

Add an informative web article or resource.
