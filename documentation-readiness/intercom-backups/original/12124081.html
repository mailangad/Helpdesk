The Loss Tree Dashboard:

  • Houses all Loss Trees created.

  • Provides search box & filter criterion to search the database for particular loss trees.

  • Provides an option to export search results from the dashboard.

  • Provides the functionality to create a new Loss Tree.

  • Provides an option to view Top Losses for a loss tree.

  • Provides an option to delete loss trees from the database.
