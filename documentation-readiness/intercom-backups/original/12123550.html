Kaizen Parent Menu: State 1 Options

  • Kaizen Dashboard: As the name suggests this option lists all the Kaizens created inside a facility in a list manner with various nested options.

  • Kaizen Settings: This option has two simultaneous functions. First, it opens up the Add New window on the right side panel. Second, it activates the State 2 of the parent menu.

  • Approval Dashboard: This option lists all the Kaizens that are awaiting approvals to move forwards into implementation.

  • Reports: This section is a statistical dashboard which helps in seeing various statistics related to Kaizen Module.

Kaizen Parent Menu: State 2 Options

  • Savings Distribution: This option tracks and allocates savings for a Kaizen as per requirement.

  • Kaizen Settings: This option has two simultaneous functions. Refer State 1 Menu Options.

  • Loss Management: This option helps create and manage the loss types connected to a Kaizen.

  • Tool Management: This option helps create new tools to be connected with a loss type.

  • Revised Due Date Reasons: This feature lets us define reasons for a delay caused in the implementation of a Kaizen.

The State 2 Menu activates the Features inside the Kaizen Module. In other words, the State 2 menu is actually the features menu.

The features buttons appear above and below the Kaizen Settings option in the parent menu section i.e. State 2 of the menu.
