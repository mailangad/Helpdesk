Step 2

Select Settings from the three tabs provided on top.

Step 3

Scroll down in the window to reach the Trade Type Window.

Step 4

Click on Create New from the top right corner of the window.

Step 5

A new Create Trade Type window will open up.

Enter the information as peer requirement and click on Save in the bottom right corner when finished.

The new Trade Type created will be added to the list. Don’t forget to check the addition!

Congratulations! We have successfully learned how to create a new Trade Type type inside F-Tag!
