A kaizen when finished can be converted into a best practice.

A best practice is essentially a kaizen that was able to solve a problem/issue in the most efficient manner. A kaizen can be set as a precedent until a more efficient process is formed. To set it as a precedent for operating in a similar way when a familiar situation/problem arises, it can be converted into a best practice.

A best practice acts as a founding solution to a problem and can be shared to other facilities for approval, suggestion, improvement and adoption! This let’s a company implement solutions in various locations and have wider feedback than can let them improve on their solutions and working methods representing continuous improvement!
