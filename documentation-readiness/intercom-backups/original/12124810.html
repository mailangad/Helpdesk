As the name suggests, Team Detail View showcases the various details of a team.

It is similar to a dashboard for the team with crucial information about a team’s performance, tools used by the team and competency details as well.

Simply put, this is the central place where you can go to gain information about workforce performance both in terms of a team as well as members detail. Certain expectancies are set by higher authorities annually (or as per requirement by the organization) which are expected to be met by the workforce. The team detail view comes in handy as it showcases not only the progress but the path of progress i.e. an employee’s current progress from start and the gap from the expected target.

A Team Detail View displays:

  • Team Summary

  • Team Competency Chart & details

  • Team Member competency & details

  • Gap Closure Performance Data

  • Tools Used

  • Export features for various data
