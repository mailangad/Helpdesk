The reports section, as the name suggests produces reports based on the submitted Suggestions by analyzing the information inside a Suggestion for example state, approach, pillars, cost etc.

The reports are statistical data that help a facility analyze how the Suggestions are being created, proceeded and concluded. By using charts and other infographic elements, the data provides a crucial insight into a facility’s workings.

Click on Reports in the parent menu to reach the reports section in the suggestion system!

The reports section in Suggestion module has three main sections:

1. Overview

As the name suggests this section provides an overview to the overall Suggestion module.

The data present in this section consists of pie charts and numbers providing the current status of the suggestions in your workplace.

2. Evaluation Rate

This section provides analytical data in the form of a chart showing values of how suggestion system is proceeding in a facility; how many suggestions are being evaluated and approved or furthered into implementation.

3. Submission Rate

This section provides analytical data in the form of a chart showing values of how many suggestions are being submitted per person in the facility.

Useful Tips!

The Reports section in the provides dashboard like search features right on the top. This can help see analytical data filtered according to search criterion!

The process to of searching is the same as in the suggestion dashboard!

Post filtering you reports according to the required data, you can export them as well.

The export option will be present in the top right corner of the window in all three sections.
