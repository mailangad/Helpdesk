The LMS System can be accessed by clicking on the LMS button in the Switch To section on the home page.

Every Module in Lean Suite has its own dashboard & parent menu.

The parent menu of the module has the main options that are displayed in the dashboard.

The main parent menu in LMS Module (Dark blue background) has five main options:

Parent Menu

LMS Module Parent Menu Options:

  • LMS Dashboard: Takes you to the LMS dashboard.

  • My Learning: Takes you to the My Learning section.

  • Course Catalog: Takes you to the central course-catalog inside LMS.

  • Instructor Panel: Opens the instructor panel (access depends on the permissions granted to a user.)

  • LMS Reports: Opens the Analytical Section of the LMS System.

All of the options mentioned above, when selected expand respectively in the right-side panel (white background) which provides details and further options for a suggestion.

Right Side Expanded Panel

(Dashboard)

The right-side panel updates as we select the option from the parent menu. The selected option is highlighted in yellow color depicting that it is active and open in the right side.

The right-side panel can be imagined as the display in a control center where the information is displayed when the control buttons (Left Menu) are activated.

The right-side panel opens simultaneously when any option is selected from the left parent menu. All the detailed data about a suggestion from its information to editing capabilities are housed in the right-side expanded panel.

This panel stays connected to the left side panel and helps the user add, edit, navigate and process a suggestion.
