Every Module in Lean Suite has its own dashboard & parent menu.

The parent menu of the module has the main options that are displayed in the dashboard.

To reach the F-Tag/Issue Tracker parent menu, select the F-Tag/Issue Tracker option on the account home page.

The main parent menu in F-Tag/Issue Tracker Module (Dark blue background) has five main options:

Parent Menu

F-Tag/Issue Tracker Module Parent Menu Options:

  • Tag Dashboard: Takes you to the F-Tag/Issue Tracker dashboard.

  • Floor Plan: Takes you to the Floor plan of the facility you are working on.

  • Kanban Board: Takes you to the visual kanban board displaying all the tags in the facility at the time.

  • Tag Reports: Takes you to the reports (analytics) section.

  • Tag Settings: Takes you to the F-Tag Configuration window.

All of the options mentioned above, when selected expand respectively in the right-side panel (white background) which provides details and further options for a F-Tag/Issue Tracker.

Right Side Expanded Panel (Dashboard)

The right-side panel updates as we select the option from the parent menu. The selected option is highlighted in yellow color depicting that it is active and open in the right side.

The right-side panel can be imagined as the display in a control center where the information is displayed when the control buttons (Left Menu) are activated.

The panel opens simultaneously when any option is selected from the left parent menu. All the detailed data about a F-Tag/Issue Tracker from its information to editing capabilities are housed in the right-side expanded panel.

This panel stays connected to the left side panel and helps the user add, edit, navigate and process a F-Tag/Issue Tracker.
