Reports are the analytical section inside Cost Management System that provide in depth graphical data to analyze financial performance of a facility.

A user can filter reports for various projects and savings based on provided filter criterion.

Useful Facts!

The Filter criterion is available for Project Pipeline & Glidepath only.

There are three main sections inside Reports:

Section 1 : Project Pipeline

This section___________

Section 2 : Glidepath

This section__________

Section 3 : Top Losses

As the name suggests, this section displays the Top Losses inside a facility.

The top losses can be displayed by year and for various loss trees created inside the cost system.

The Top Loss section provides a detail breakdown of the data for a Department, Line, Asset and Workstation as well.
