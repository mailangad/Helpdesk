The Deleting process involves making the issue Inactive rather than deleting the issue entirely.

Step 1

Navigate to Tag Settings in the parent menu of F-Tag.

Need Help?

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4672899

Step 2

Select Settings from the three provided tabs on top.

Step 3

Navigate to the top right corner above the Default Due Date list.

Click on the arrow on the right and select Issues View.

This will open the Issues View Window.

Useful Facts!

The Settings tab in F-Tag helps us set up 4 settings, 2 of which are set in one place while the other two have their own respective windows.

The Default Due Date & Issues share the same window.

The Priority and Trade Type have their respective windows.

Step 4

Choose the Pillar whose issue needs to be edited.

Navigate to the end of the row and click on the three dots icon under the Action column.

Two options will show up that allows a user to edit or make the issue active/inactive

Inactive/Active

Select the Inactive/Active button in order to make the issue active or inactive as per preference.

Useful Facts!

The issue stays in the database and is available to be called upon by making it active.

When the issue is in Inactive State, it is not available to choose from in the drop-down menu of the Issues Field while creating a new F-Tag!

Edit

Clicking on the second Edit option from the window.

A new Update Issue window will open up.

Choose the Issue you wish to edit.Enter the Sub-issue information you wish to change.

Click on Save when you are finished.
