Once a user/employee creates a Team, it goes into the database where it becomes available viewing, analyzing and exporting important statistics.

A company using Lean Suite may have multiple teams.

A Skill Matrix Dashboard is the central place where all the teams created inside a facility are listed.

You can reach the Skill Matrix dashboard by clicking on the Skill Matrixbutton on your account home page.

This is what a typical Skill Matrix Dashboard looks like:

The Skill Matrix Dashboard:

  • Shows the number of the Teams inside the facility.

  • Lists all Teams inside a facility.

  • Helps you find a particular team.

  • Filters the teams based on specific criteria.

Useful Tips!

Dashboard Display Options

There is a small option present in the top right side of the dashboard that help in modifying the display.

  • View (Table or List) : The default view is by table that has various headings. You can change the view list that displays the Skill Matrix in a card manner.
