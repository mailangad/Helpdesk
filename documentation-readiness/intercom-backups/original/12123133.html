The procedure to add an approver/implementer to a suggestion is different depending upon the user preference.

A user can choose to open a suggestion in the side window or detail view.

For this instruction we will open the suggestion in the detail window.

Follow the steps below to add an approver/implementer to a suggestion !

Step 1

Open the Suggestion you wish to add an approver/implementer.

Need Help ?

Step 2

Choose from the options below!

Adding an Approver

Click on the Add Approver button from the options on the top bar.

A small drop-down window with two options will open up. Select the Add Approver option.

The Add Approver button will add a new Required Approver(s) sub-field in the suggestion below. You can scroll down to see the input field active.

Enter the name of the user you wish to add and select from the options that show up. Make sure you click on the Green Tick mark on the right when you are done to save the changes.

In case you change your mind, simply click the red cross and the field will be removed from the suggestion.

Adding an Implementor

Click on the Add Approver button from the options on the top bar.

A small drop-down window with two options will open up. Select the Add Implementor option.

The Add Implementor button will add a new Required Implementor(s) sub-field in the suggestion below. You can scroll down to see the input field active.

Enter the name of the user you wish to add and select from the options that show up. Make sure you click on the Green Tick mark on the right when you are done to save the changes.

In case you change your mind, simply click the red cross and the field will be removed from the suggestion

Useful Tips !

You can add an Approver at the initial stage of the suggestion proceedings.

You can add an implementor at multiple stages of a suggestion proceedings.

Congratulations! You have successfully learned how to add an approver/implementer to a suggestion!
