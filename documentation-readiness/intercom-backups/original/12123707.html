The Kaizen side window displays information in a summarized manner with 5 different fields that are collapsible & expandable thereby making the whole window scrollable owing to the different size it may have.

The different fields in a side window are as follows:

  • Details

Displays information entered while creating a kaizen.

  • Sections

Displays Phases inside a Kaizen.

Useful Fact!

The number phases displayed in this section is the same as the phases of the methodology a kaizen has.

  • URL Attach

This field is not collapsible but stays active. It let’ a user attach a relevant web address with a description to a kaizen.

  • Attachment

This is a drag & drop box which let’s you attach further items to a kaizen.

  • Activity

This records the activity as a Kaizen proceeds in implementation
