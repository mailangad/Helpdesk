The parent menu of the module has the main options that are displayed in the dashboard.

To reach the Best Practice parent menu, select the Best Practice option on the account home page.

The main parent menu in Best Practice Module (Dark blue background) has two main options:

Parent Menu

Best Practice Module Parent Menu Options:

  • Best Practice (Dashboard): Takes you to the Best Practice dashboard.

  • Best Practice Report: Takes you to the reports (analytics) section.

Useful Tips!

Since a best practice is essentially a kaizen, the parent menu changes to the same as the State 1 parent menu in kaizen whenever the Create New best practice window is opened.

It provides a user an easy linkage to the settings that will be required for the best practice creation!

Learn more about the State 1 Menu here!

All of the options mentioned above, when selected expand respectively in the right-side panel (white background) which provides details and further options for a Best Practice.

Right Side Expanded Panel

(Dashboard)

The right-side panel updates as we select the option from the parent menu. The selected option is highlighted in yellow color depicting that it is active and open in the right side.

The right-side panel can be imagined as the display in a control center where the information is displayed when the control buttons (Left Menu) are activated.

The right-side panel opens simultaneously when any option is selected from the left parent menu. All the detailed data about a Best Practice from its information to editing capabilities are housed in the right-side expanded panel.

This panel stays connected to the left side panel and helps the user add, edit, navigate and process a Best Practice.
