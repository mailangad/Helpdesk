An F-Tag also known as Failure Tag or Issue tracker is a module inside Lean Suite that provides the functionality of solving a problem or issue inside a workspace by creating an issue that is tracked by collecting required data and assigning a person to the problem.

It takes a holistic approach where a problem can be brought into attention based on its priority and then tackled with proper documentation like cost, savings etc.

In a large infrastructure where small and big problems can arise in day-to-day functions be it any department, an F-tag provides a system to tackle the problem as soon as possible in the most efficient manner while documenting it to learn from it further.
