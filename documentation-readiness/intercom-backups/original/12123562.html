Once a user/employee creates a Kaizen, it goes into the database where it becomes available for editing, analysis and proceeding further.

A company using Lean Suite may have hundreds of Kaizens being created by their many employees.

A Kaizen Dashboard is the central place where all the Kaizens created are listed and are available to view, edit, proceed etc.

This is what a typical Kaizen Dashboard looks like:

The Kaizen Dashboard:

  • Lists all created Kaizens.

  • Helps you find your submitted Kaizen.

  • Filters the Kaizen based on specific criteria.

  • Provides a .csv export feature for the database.

  • Views the status of best practice via color coding tags.

The kaizen dashboard lists the created Kaizens under various headings (20 to be exact). These headings are both general (ID, Title etc.) and specific (Loss type, Project Source etc.) in manner and help in gaining summarized information about a submitted Kaizen.

The Headings in the dashboard are derived from the various information fields that we fill while creating a kaizen along with various other options are used to edit and update a Kaizen during its implementation process.

Tips & Tricks

Dashboard Display Options

There are two small options located in the top right side of the dashboard that help in modifying the display.

  • View (Table or List) : The default view is by table that has various headings. You can change the view list that displays the Kaizens in list manner with lesser information as compared to table view.

  • Page Size : The number on the right side let’s you choose how many kaizens are displayed at a time on the page. You can choose from the available options or enter a custom number.
