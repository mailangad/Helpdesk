The Suggestion side window displays information in a summarized manner with 8 different fields that are collapsible & expandable thereby making the whole window scrollable owing to the different size it may have.

The different fields in a side window are as follows:

Field Names

Description

  • Labels

Just as the name suggests, this field lets you enter labels for your suggestions making it easier to identify in the database.

  • Details

Displays information entered while creating a Suggestion.

  • Required Approver

As the name suggests this fields provides you a drop-down menu to choose from the user database and appoint an approver who has authority in the suggestion related area.

  • Implementor

As the name suggests this fields provides you a drop-down menu to choose from the user database and appoint an implementor who has authority in the suggestion related area.

  • Problem Description

This section provides a rich text editor to describe the suggestion reason of creation and problem in focus.

  • Recommended Suggestion

This section provides a rich text editor to describe a recommended suggestion for the problem which has been bought into attention.

  • Attachment

A drag & drop box option to attach external data into a suggestion.

  • Activity

This records the activity as a suggestion proceeds in getting feedback or implementation.
