Step 2

Once you reach the Loss Management dashboard, navigate to the top right corner and click on Add Loss button.

Step 3

A new window named Add Loss Type, will open up with various information fields that will collect data about the loss type being created.

There are 6 information fields in the Add Loss Window:

Field Name

Field Dropdown Options

Loss Category

This field provides the option to choose the category in which you wish to nest your new loss type. This let’s a user organize the loss types that can be added to a kaizen.

Useful Facts!

A user can choose a pre-existing category to nest the new type in or create a new category based on preference.

Go below to learn more about how to add a new category!

Loss Type

This field let’s a user enter the name of the new Loss type you wish to create.

Loss Type Category

This field has three options Casual, Resultant & Both which let’s you choose what type of loss you wish to create.

Useful facts!

The Loss type category is different from Loss Category since the parameters of segregation are different. The category defines the overall segregation based on internal bigger factors and the loss type category segregates based on the proceedings i.e. Casual or Resultant

Threshold Type

This field provides two options to chose from, Amount & Time.

Process Impact

This field provides four options to chose from, Upstream, Downstream, None & Both.

Asset Impact Level

This field provides two options to chose from, Asset & Workstation.

Enter the information in the fields as per your preference.

Step 4

Once you have entered information in all the fields, click on submit. A green colored pop up confirm the submission of your new Loss Type.

Congratulations! We have successfully learned how to add a new loss type in kaizen!
