Section: Description

Simply put, Description section lets you add a Description to the kaizen. This description can be used to communicate important information that will describe the problem/goal that is being handled by the kaizen.

Let’s go ahead and a Description to our kaizen in Plan Phase!

Step 1

Add the Description section from the available list to the required phase.

Useful Facts!

When a new section is added it appears under the previous section; in this case Team Section.

Step 2

Expand the section by clicking anywhere in the section field, or on the arrow on the right side.

The arrow can also be used to collapse the section.

Step 3

The section provides a Rich Text Editor for input.

Enter the description on the field provided and click on Save when you are finished.

Collapse the section after saving the description!
