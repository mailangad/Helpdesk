The Activity Field is the smallest section when a Best Practice is opened up.

The activity section:

  • Records or hold the activity inside a Best Practice i.e. whatever changes that take place during the progress of a Best Practice.

  • Provides a comment section for the users/employees to interact and share insights as a Best Practice proceeds.

The Activity Section has 3 sections as follows:

All

The section shows both comments & history changes all together with the latest on top.

Comments

This section shows just the comments on a Best Practice with the latest on top.

History

This section shows just the changes on a Best Practice with the latest on top.
