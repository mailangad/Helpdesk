Questions, the building blocks of the template are added to pages or sections inside page.

The questions inside a page or section have three main components:

  1. Question Field

  2. Response/Answer Field

  3. Response Properties

Let's go ahead and create a question to get a hands-on approach!

Step 1

Open the Lean Creator window by creating a new template or opening an existing one.

We'll refer to the question as the "Question Card" to understand it better.

The very first field in the question card is the Question itself, a simple text field, where you add the main content, be it a question, instruction or a text input as per the response required.

Here we have entered "Sample Question 1" as the question text.

Step 2

Once the question is entered, we move on to choose the response.

The Response field is a drop-down field with multiple choices offering a variety of ways to answer and efficiently collect data.

Once a Response type is chosen, the response options are updated allowing us to edit and tailor the responses to the question.

The response options are located just below the question field. There are three main response options :

Required

This allows us to mark a question as a mandatory requirement.

While entering responses, the report cannot be submitted is a question marked as required is not answered.

Response Properties

These properties are related to the type of response selected for the question.

For example, when a multiple-choice question is selected, the response properties field is where we can set the choices for the question.

Add Rule

This property is available for a few types of responses only. This allows us to further add an action by setting a trigger when a certain response is recorded.

The Add Rule property is available for some of the response types only.
