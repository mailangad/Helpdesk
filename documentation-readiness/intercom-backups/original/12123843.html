Section: Tool

The Tool section simply lets you add the tools that will be required to handle the issue or complete the process related to the Kaizen!

You can add multiple tools, enter the quantity for each tool, the tool expertise required as well as the tool lead!

Let’s go ahead and add tools to our Plan Phase!

Step 1

Add the Tool section from the available list to the required phase.

Useful Facts!

When a new section is added it appears under the previous section; in this case RCA Section.

Step 2

Expand the section by clicking anywhere in the section field, or on the arrow on the right side.

The arrow can also be used to collapse the section.

Initially, there would be no tools added as the section has been added for the first time to the phase.

Click on Add Tools.

Step 3

The Add Tools button will be replaced by a drop-down menu with options of tools to add.

Click on the down arrow to view the options.

Select the tool you wish to add.

Step 4

The Tool will appear in a list manner with some options next to it!

Tips & Tricks

Once a tool has been added, you can again click the drop-down arrow to view options and add more tools to the section!

Step 5

The new options available allow you to add Tool Lead, Expertise and Tool Usage Count!

There are two ways to add this information into a tool:

  1. Through the Tool List Card (Adding Tool Lead & Usage Count)

  2. Through Edit Tool Window (Adding all three)
