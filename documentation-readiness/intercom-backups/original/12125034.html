The Tag Settings window is scrollable. The Priority & Trade Type windows are available side by side right below the Default Due Date/Issues window. You can reach it simply by scrolling down in the Tag Settings window.

As the name suggests, Priority is a property that can be attached to an F-Tag while creation to indicate the urgency required for the issue’s resolution.

The Priority forms a Sub-field when creating a Default Due Dates.

Inside F-Tag, priority can be used to add a level of detail to the urgency in terms of Default Due Days of an issue!

Different Priorities can be created with inside F-Tag with their respective Due Days and Description and these priorities become available to choose from while creating an F-Tag as well as Default Due Date!

Thereafter, the number of days that are required to solve a particular issue can be pulled from the Priority that has been already set.

The Window lists all priorities in a list manner with their default due days in front of the name.

Tips & Tricks

Use the drop-down option on the bottom left to control how many priorities are visible at a time.
