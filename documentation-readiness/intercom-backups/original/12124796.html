Reports inside Skill Matrix is an analytical section that provides comprehensive data about the competency and hence tool usage inside Lean Suite.

As we know competency is directly related to the tools inside Lean Sute and therefore it serves as an effective measure of an employee’s Skill.

The reports section covers the statistics of this competency along with its forming part, tools in two sections.

You can reach the Reports section from the main parent menu of Skill Matrix.

The 2 main sections inside Reports are as follows:

Competency

As the name suggests this section displays the competency of various employees in the facility.

This section allows you to:

  • View competency

  • Search using search & filter criterion

  • Export all user's competency report

  • Export filtered competency data

Statistics

This section provides statistical data about the tool usage inside a facility.

This section allows you to:

  • View Cumulative Tool Usage

  • View Unique Tool Usage

  • View Team Distribution in Facility

  • View Team Count by Pillar

  • Export Statistical data
