Context Quotes

Once a Kaizen is created, the module gives various options of attaching information to a Kaizen which is helpful for the successful implementation of the Kaizen. This helps it follow a Kaizen phase wise approach by accepting feedback into every phase.

Step 1

Open the kaizen you wish to attach information or data to.

You can either open a kaizen in side window or in a detail view.

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4672960

Step 2

You can add information to a Kaizen in 4 different ways. Choose from below to learn further!

🔖Attach

Attach a file of any format.

➰Sketch

Add an explanatory sketch.

🖼️Photo

Add a photo by using device camera.

🌐Web URL

Add an informative web article or resource.
