Tool Management is a nested part of the Loss Management feature.

When a new Tool is created, it gets added to the database and is available to view through the Tool Management Dashboard similar to a Kaizen Dashboard.

Tool Management helps in organized handling of tools crucial for continuous improvement. It streamlines the identification, organization, and maintenance of these tools, ensuring their effective deployment to address specific losses, thereby enhancing the overall efficiency of the improvement process.

Various Tools can be created and added to the Loss types.

They consequently help keep a record of how much resources are used when a loss is encountered in a Kaizen and particular tools are deployed to mitigate it.

A facility can create a database of all the tools at disposal and then add them to different loss types as per preference or situational requirement.

Useful Tips!

The Tool Management Dashboard displays the data in page layout with a maximum of 20 Results at a time.

All the new tools created are added at the end of the list i.e. if the number of tools is more than 20, all the other will be listed in another page and so on.
