Follow the steps to open up the submitted quizzes inside LMS.

Useful Facts!

While creating quiz questions, correct answers are also input into the process. The LMS System can automatically mark some questions by comparing them to the correct answers.

The result of the question can be overridden by the instructor while marking the quizzes.

Step 1

Once you reach the Your Tasks dashboard click on the quiz you wish to mark.

A new side overlay Quiz Window will show up. This is where all the answers submitted are viewed and are available to mark!

Tips & Tricks

You can set the filter criteria to Pending to quickly list all the quizzes that have not been marked!

There might be many questions in a quiz that need to be marked.

In such cases, just like the Course/Quiz Curation process, an instructor can mark few answers and Save the quiz to come back later and continue the process. The instructor can also Cancel the process which will not save any progress.

The Top Bar displays the statistical data as the quiz is being marked i.e. Correct Answersm Incorrect answers, marks obtained etc.

The two main buttons are

Save & Cancel.

The save and cancel are window options.

Useful Facts!

The Pending option signifies that the question is pending for marking.

Each quiz question has a drop-down menu with three options.

These are the options that are instrumental in Marking the quizzes.

  • Pending

  • Correct

  • Incorrect

For the short answer Questions there is an additional Rich Text Editor Box for an instructor to provide comment on the answers.

The True or False questions have a toggle button to change the answer from true or false and mark the answers provided accordingly.

Step 2

Mark all the questions with appropriate details.

Once all the questions are marked, click on the Save button on the top bar.

The quiz Status updates to Passed or Failed when the marking is complete. If a question is left unmarked, the status changes to Pending.

Congratulations Instructor! You have learned how to mark quizzes and can now mark your very first quiz!
