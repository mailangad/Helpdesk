What are User Re-Assignments?

The process of "sending back" a Tag, also referred to as User Re-Assignment, can have significant implications in real-life scenarios, particularly when the issue at hand is important and requires urgent attention. When an F-Tag (a type of User Re-Assignment) is sent back, it often leads to crucial time loss. This delay can subsequently hinder the timely resolution of the issue, intensifying the problem and potentially leading to further complications.

To avoid the risk of such delays and ensure that critical issues are addressed promptly, Lean Suite provides the option to limit the instances of User Re-Assignments. By minimizing the frequency of these re-assignments, the process can become more streamlined and efficient, ensuring that issues are resolved in a timely manner without multiple back-and-forth, which can be crucial in urgent situations.

How to edit User Re-Assignments?

Step 1

Navigate to Tag Settings in the parent menu of F-Tag.

Step 2

Select General Configuration from the three provided tabs on top.

Step 3

Useful Facts!

Make sure the Toggle Button in front of Track User Re-Assignments is turned on.

The toggle button can be turned off to stop the tracking of assignments of tags!

Navigate to the Counts section.

Useful Facts!

The number represents the times a tag can be reassigned. A tag can be limited to re-assignments by users and made sure is implemented on time.

Use the + or - buttons to increase or decrease the number of times a tag can be reassigned.

Step 4

Click on Save after you have set the desired number to save the settings.
