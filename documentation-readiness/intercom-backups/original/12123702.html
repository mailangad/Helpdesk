The Activity Field is the smallest section when a kaizen is opened up.

The activity section:

  • Records or hold the activity inside a Kaizen i.e. whatever changes that take place during the progress of a kaizen.

  • Provides a comment section for the users/employees to interact and share insights as a kaizen proceeds.

The Activity Section has 3 sections as follows:

All

The section shows both comments & history changes all together with the latest on top.

Comments

This section shows just the comments on a Kaizen with the latest on top.

History

This section shows just the changes on a Kaizen with the latest on top.
