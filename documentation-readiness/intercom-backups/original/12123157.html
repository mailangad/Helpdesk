Step 2

There are 2 ways to open a Suggestion:

  • Side Window : A Side window displays a summarized view of the Suggestion information in a smaller scrollable area with the Suggestion dashboard still open. This lets you choose any Suggestion and get an overview of the information inside it simultaneously.

To open the side window select & click the Suggestion you wish to open. A side window will pop up with the Suggestion information inside it.

Suggestion Side Window Overlayed on the right side

  • Suggestion Detail View : This view opens up the Suggestion in a full page view with different sections available to see at once. This displays more information as compared to the side window and there is no dashboard visible in this view.

To open the Suggestion detail view click on the Expand button placed on the left side of the ID (refer picture below) located on the top left corner of the side window.

A new tab will open up with the suggestion shown in full page view.

Suggestion Detail View

Pointers!

The Side window & Suggestion Detailed view display the same information in different ways!
