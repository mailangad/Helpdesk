The Loss Tree Detail View as the name suggests, details out the Loss tree and provides information as well as options relating to the losses inside Loss Tree.

This is what a typical Loss Tree Detail View looks like:

A Loss Tree Detail View:

  • Views Losses in its given date range starting from the highest to the lowest.

  • Provides a range of filter criterion to filter the losses in the given tree.

  • Views Top Losses inside the Loss Tree.

  • Provides a functionality to export Loss Tree Data.

  • Provides the functionality to take an action on the losses by creating a Kaizen.

  • View the Kaizens created for the losses inside the Tree.

There are 2 main sections inside a Loss Tree Detail View:

Section 1: Filter Criterion

This section allows you to filter the losses with various criterion.

It also allows you to export data for a loss tree.

Section 2: Loss Results

This section views all the losses within the Loss Tree Date range.

It shows the Date range and the total loss amount on the top bar and details out the loss breakdown in the results below.

It also allows us to view top losses and take an action on the loss results by creating a kaizen.
