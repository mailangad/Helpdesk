The LMS Dashboard is the central place where a user can see the course record in various formats. It acts the central place where all the information about the user’s learning progress is shown at a high level.

This is what a typical LMS Dashboard looks like:

The LMS Dashboard:

  • Shows record of courses completed, in progress, course hours and certificates earned.

  • Shows details of the courses in progress via a dedicated section In Progress.

  • Shows details of the courses in the wishlist via a dedicated section Not Started.

Useful Facts!

There is a View All clickable option present to the extreme right of the In Progress & Not Started sections.

The View All button acts as a connection between the LMS Dashboard and the My Learning Section. The button represents an option to see all the courses available for the user to choose from. As we know the LMS Dashboard offers a high-level overview, the View All button takes you the My Learning section where all the courses a user has enrolled or wishes to enroll in are listed!
