Step 2

Select the Kaizen Module from your account home page.

Step 3

Once the Kaizen dashboard shows up, select Kaizen Settings from the main left Settings Panel.

Step 4

The Kaizen Settings will open up with a Add New window. Click on the Add Kaizen Type option at the bottom (Scroll down if needed).

Kaizen methodology is nested under Kaizen type in Lean Suite.

Once you create a new Kaizen type, you can create/add a new kaizen methodology inside the type panel.

Step 5

The Enter Kaizen Type box will show up. Enter the name for your new Kaizen type and click on save to create a new type.

A green window with Kaizen Type Added Successfully will show up to confirm the new addition.

Congratulations, you have successfully added a new type in Kaizen Module. 😀

Learn further about the nested kaizen methodology in Kaizen Type Settings.
