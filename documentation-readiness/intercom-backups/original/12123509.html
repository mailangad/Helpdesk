Step 1

Navigate to the List of Tools attached to a loss type in the window.

There are two columns, Tools & Level Of Expertise. The editing option is present in the second column i.e. Level of Expertise.

Useful Facts

The Level Of Expertise as the name suggests represent the proficiency of the tool in a particular loss type. Continue below to learn how to set the level as per requirement!

Click on the three black dots under the second column.

Step 2

Two options namely Edit & Delete will show up. Click on Edit to proceed further.

  • Edit will open up further option to set the level of expertise

  • Delete option provides the option to detach a tool from the loss type by deleting it.

Step 3

A small widget will become active that let’s a user increase or decrease the level of expertise by using + or - signs or by typing the value in the box.

Useful Tips!

The maximum value of expertise that can be entered is 5.

If any value more that that is entered, a warning message is displayed.

Step 4

Once you have entered the desired value click on Save on the bottom. The new changes will be applied and the list of tools will be update showing the new value.
