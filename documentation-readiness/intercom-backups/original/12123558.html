The parent menu of the module has the main options that are displayed in the dashboard.

To reach the kaizen parent menu, select the Kaizen option on the account home page.

The main parent menu in Kaizen (Dark blue background) has two states:

State 1

State one is available right when you enter into the Kaizen Module by selecting the Kaizen option from your account home page.

Kaizen Module Parent Menu Options:

  • Kaizen Dashboard

  • Kaizen Settings

  • Approval Dashboard

  • Reports

State 2

State 2 becomes active when you select the Kaizen Settings option from the state 1. The other options are hidden & new options show up when this option is selected.

Kaizen Settings & Features Panel

  • Savings Distribution

  • Kaizen Settings

  • Loss Management

  • Tool Management

  • Revised Due Date Reasons

The Tool Management option is an extended feature to the Loss Management that helps create new tools to be connected with a loss type and also provides a dashboard type record of all tools created.

The last option Revised Due Date Reasons is a smaller augmented feature in Kaizen that lets us define reasons for a delay caused in the implementation of a Kaizen. When a Kaizen is created, it has a start date and a due date which is subject to change pertaining to various factors such as technical, labor, mechanical, logistical etc. (factors depend upon the company/industry). Every time a Kaizen’s due date is changed Lean Suite requires a reason to be attached to the change for proper documentation and transparency in the proceedings. This feature helps in creating the reasons tat can be attached when changing the due date.

All of the options mentioned above in the two states, when selected expand respectively in the right side panel (white background) which provides details and further options for a Kaizen.

Right Side Expanded Panel

The right side panel updates as we select the option from the left menu. The selected option is highlighted in yellow color depicting that it is active and open in the right side.

The right side panel can be imagined as the display in a control center where the information is displayed when the control buttons (Left Menu) are activated.

The right side panel opens simultaneously when any option is selected from the left parent menu (both state 1 & state 2). All the detailed data about a kaizen from its information to editing capabilities are housed in the right side expanded panel.

This panel stays connected to the left side panel and helps the user add, edit, navigate and process a kaizen.
