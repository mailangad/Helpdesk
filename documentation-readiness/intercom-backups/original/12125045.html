The reports section, as the name suggests produces reports based on the submitted F-Tags by analyzing the information inside a F-Tag for example pillars, distribution etc.

The reports are statistical data that help a facility analyze how the F-Tags are being created, proceeded and concluded. By using charts and other infographic elements, the data provides a crucial insight into a facility’s workings.

The reports section in F-Tag module has four main sections:

General Analytics

As the name suggests this section gives an overview of the tag database.

Pillar Analytics

Provides a pillar specific analytics data.

Tag Distribution

Shows a visual representation of where the tags are physically on the floor plan of the facility.

Time Series Analytics

Provides the tag analytical data over a period of time.

Useful Tips!

The Reports section in the F-Tag module provides dashboard like search features right on the top. This can help see analytical data filtered according to search criterion!

The process to of searching is the same as in the F-Tag dashboard!
