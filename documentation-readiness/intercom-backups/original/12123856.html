Step 3

The Import History dashboard will show up with all the imports made in the past.

Useful Facts!

The Import History keeps a record of the imported data that forms the database for Cost Management Analysis. A set of data (uploaded files) can be deleted from the database if required.

Use the delete icon in front of the imported data to remove it from the database.

Step 4

Choose and Click on the file for which you wish to see the details.

A new File Detail window will open up with all the details of the uploaded data.

Tips & Tricks

You can use the drop-down field in the top left corner to choose the files for which you wish to see the details!

All the files uploaded are available to choose from in this drop-down menu.
