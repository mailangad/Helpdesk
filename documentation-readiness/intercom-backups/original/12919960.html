Once you create a new template, the Lean Creator window open up with a page, a question created by default.

This is how a typical new creator window looks like.

The questions and responses created in a template are contained inside pages and sections. Let's have a look at the pages and sections.

Pages & Sections

The questions created in a template can either be inside a page or inside a section.

The hierarchal order goes this way:

  • Top Level - Page

  • Second Level - Section

  • Third Level - Question & responses.

You can create multiple pages in your template.

Inside each page you can either create one or multiple sections, or directly add questions.

Let's take a look on how pages and sections stores answers!

Sections Inside Pages

Let's move on and see what a section is and how can we add a section inside a page.

We will use the Add Section button right next to the add question button we used previously.

Once we create a section, a page like title named Section 5 is added below the last question with one question inside the section be default.

This creates a sub section inside the page. The question format remains the same, but it simply gets housed inside a section for grouping or segregation purposes as per requirement of the template.

Notice that there is no Add Section button next to the Add Question inside the section. This is because the section is the last hierarchal level. We can create multiple sections inside a page but a section cannot be created inside an already existing section.

Similar to the question inside pages, the currently active/selected question will be displayed in a light blue background.

Page & Section Properties

We have covered how to add questions inside pages, adding new section and questions inside that section as well.

Before we move on to the details of the question let's look at some of the properties and options available for editing pages and sections!

Adding New Page

A new creator window opens up with page added as default.

To add another page, scroll down to the bottom of a page and click on the Add New page button located in the bottom left corner of the page.

A new Page 2 is added with one question inside by default.

You can create multiple pages using the add new page as per requirement. The button will be at the end of the window on the bottom left corner.

Collapsing/Expanding Pages

When creating a template with multiple pages, the collapse/expand button can help quickly navigate through multiple pages saving time.

Use the arrow located at the right end corner of the page name to collapse/expand pages inside a template.

The image below shows all pages collapsed, making the navigation easier.

Renaming Pages and Sections

When a new page or a section is created it is named by default as Page/Section 2,3,4 and so on in a numeric manner.

The name can be changed simply by clicking on the default name and typing in the name you wish to assign.

The editing field becomes active once you click on the name and you can simply proceed to type in the new name.

Reordering Questions/Sections

When a new question/section is added inside a page it usually goes to the end of the last question/section by default.

At times rearrangement of the question maybe required.

Both the questions and sections as well as questions inside a section can be rearranged easily using the reorder button located on the left side of each question and section!

Simply click and drag the question/section in the place you want.

At last, the pages, sections and questions can be deleted easily whenever required.

The delete button is present at the rightmost corner of each question, section and page.

By default the button is always visible for pages and sections but becomes active when you enter the question space.

Preview Window

One of the main components of the Leab Creator Window is the preview window located on the right side of the page.

While we were making the changes, adding pages, questions, sections, the preview window was updating simultaneously.

The window will show how the question will appear to the end user while using the template. This serves as good feedback while creating question and saves the editing and modification time.

By default the preview window displays one page at a time

You can scroll down to the bottom of the window and click on Next Page button.

Notice how each question has Drag and drop box as response. This is because by default the question response type is set as the template type chose when creating a new template.

In our case we chose Assignment/Skill Matrix as the type which by default has a drag and drop box.

These input fields can be changed according to preference.
