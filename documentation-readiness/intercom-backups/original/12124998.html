F-Tag is designed to deal with issues and aims at seeing them resolved effectively, efficiently and quickly. In order to achieve these some preferences needs to be setup according to the company’s work requirements. This process can be called as configuring the F-Tag for your workspace so that all issues are resolved in a set standard manner!

The options available inside the Tag Settings are the ones that let you configure the F-Tag Module for your workspace. There are 6 main settings houses under different tabs and windows that are available to configure F-Tag for your workspace!

We will go through all of them in the order listed below!
