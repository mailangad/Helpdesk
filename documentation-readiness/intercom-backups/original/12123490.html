Step 1

Navigate to the Loss Management Dashboard.

Need Help?

https://app.intercom.com/a/apps/lhkbxbyv/knowledge-hub/internal-article/4672949

Step 2

Select and click on the Loss in under which a tool needs to be added.

A new side window Default Tools will show up on the right side of the dashboard area.

Step 3

The default tools window displays:

  • Basic information about the loss i.e. Loss Type & Loss Category

  • Provides a drop down menu for searching tools

  • Displays a list of the tools attached to that loss

Now, navigate to the Search Default Tools box and click on the drop down arrow.

Step 4

Select and click on the tool you wish to add to your loss. Scroll down if needed.

Useful Facts!

The list of tools displayed in the drop down options is all the tools present in the database. This is the same list of tools available in the Tool Management Dashboard.

If you wish to add a particular tool to your loss which is not present in the list, you can create a new tool via the tool management feature and it will automatically become available in the list to chose from!

Step 5

When you have chosen the tool to be added, it will show up in the list below of the tools added!

Congratulations! We have successfully learned how to add a tool to an existing Loss Type in Kaizen!
