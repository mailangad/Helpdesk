Step 1

Useful Facts!

A user can only export data from a Kaizen in the Kaizen detail view.

Open the Kaizen from which you wish to export data in detail view.

Step 2

Navigate and click on the pdf icon near the workflow button.

A Save As dialogue window (depending on windows or mac users) will appear.

Step 3

Choose your preferred location on the system you are using and enter the name of the file you want to export.

Click on Save when you are done.

This process to further a Kaizen to next phase requires an action of the concerned authority. (the authority is granted based on permissions).
