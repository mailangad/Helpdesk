The reports section, as the name suggests produces reports based on the submitted kaizens by analyzing the information inside a Kaizen for example state, approach, pillars, cost etc.

The reports are statistical data that help a facility analyze how the kaizens are being created, proceeded and concluded. By using charts and other infographic elements, the data provides a crucial insight into a facility’s workings.

The reports section in Kaizen module has two main sections:

Overview

As the name suggests this section provides an overview to the overall kaizen module.

The data present in this section consists of:

  • Kaizen By State

  • Kaizen By Approach

  • Kaizen Impact

  • Number of Kaizens By Pillar

Benefit & Cost

The Benefits & Cost section provides more details into the statistical data. Their are comparative numerical values based on the information pulled from kaizen.

The data present in this section consists of :

  • Average Days to Close

  • Total benefit

  • Total Cost

  • Total Savings

  • Detailed Savings Data

  • Benefits Vs Cost Comparison

  • Target Vs Actual Benefit

  • Target Vs Actual Cost
